设计与证据：[怪物系统](docs/MONSTER_ARCHITECTURE.zh-CN.md) · [PoE 天赋适配与平衡](docs/POE_PASSIVE_ADAPTATION.zh-CN.md) · [普通装备词缀研究](docs/POE_AFFIX_REFERENCE.zh-CN.md)

## v0.3.0：投射物生命周期与伤害机制

这一版围绕底层组合规则重构战斗，并用“龙卷射击”验证机制，而非只增加技能数量。完整设计、伤害演算、扩展边界与验收场景见 [战斗底层设计](docs/COMBAT_ARCHITECTURE.zh-CN.md)。

- **载体与伤害分离**：母箭、子箭、直接法术和爆炸分别持有自己的伤害包与标签；爆炸不继承投射物增伤
- **自然结束先仲裁**：射程边界先判断分裂、返回，再决定是否自然结束；总寿命是不可延长的上限
- **龙卷组合**：默认 3 枚母箭，每枚分裂 3 枚径向子箭；棱光长弓增加到 5 枚母箭 / 15 枚子箭
- **归航披风**：子箭到射程后，取人物此刻中心方向返回一次，穿过中心继续直飞；不是持续追踪，不刷新寿命
- **终焰护符**：自然飞行结束触发独立火焰爆炸。仅爆炸装备在射程处爆炸；配合返回则在子箭出生 1.7 秒后爆炸
- **明确排除**：母箭被分裂消耗、普通箭碰撞耗尽、死亡、重置与容量取消均不触发自然结束爆炸
- **逐分量结算**：全局提高作用于全部伤害；投射物提高仅作用于箭；元素提高仅作用于火焰 / 冰冷 / 闪电。同一分量的“提高”相加，独立“更多”相乘
- **施放快照**：属性、效果和配方在施放时锁定；子箭、返回与爆炸继承同一快照。敌方抗性在实际命中时读取
- **可靠命中**：精确分段到射程 / 寿命边界，扫掠碰撞按距离先后结算；每枚箭每阶段每敌人一次，不同子箭与爆炸可分别命中
- **F6 机制面板**：实际穿脱三件机制装备、查看母箭 / 子箭 / 爆炸的公式拆解、最近真实伤害和生命周期记录

### 30 秒体验组合

1. 按 **F6**，点击 **试装完整组合**：龙卷进入槽 1，三件机制装备自动穿戴并保存
2. 关闭面板，按 **1** 释放：绿色母箭 → 青色子箭 → 紫色返回箭 → 橙色爆炸
3. 再按 **F6** 查看真实记录；独立开关返回、爆炸和长弓，比较行为与增伤

目前不含伤害转换、暴击、持续伤害、持续追踪、分叉/连锁投射物或任意用户脚本效果编辑器。`DamageResolver` 已支持独立“更多”与抗性参数，当前装备仅投放“提高”词缀，敌人默认抗性为零。这些是明确的扩展接口，不代表已有对应玩法。

## v0.2.0 功能：天赋星图、珠宝与格子背包

这一版把旧的五条天赋列表替换为可平移、缩放的连接式大型天赋树，并加入普通珠宝系统。图形、名称与节点布局为本项目原创；机制参考 PoE 的基础天赋槽与珠宝，不包含其资产或原始天赋布局。

### 天赋星图

- 181 个节点、360 条连线、六个属性主题分区；包含 24 个核心天赋、12 个珠宝槽与环路和跨区路线
- 起点免费激活；只能分配与现有已点路线相连的节点，每个节点消耗 1 点
- 新角色有 5 点，升级获得更多；最早的珠宝槽只需沿路线投入 3 点
- 退回单个节点必须保证剩余已点节点仍与起点连通；也可免费重置全树
- 退回珠宝槽或重置时，里面的珠宝会安全回到珠宝背包
- 选择节点查看属性和状态；滚轮缩放，拖动空白处或中键平移；工具栏可回到起点、缩放或总览
- 各种状态用形状、文字与颜色区分，已点路线为金色，可点邻接节点高亮

### 珠宝

- 三种原创基底；魔法珠宝最多 2 条词缀（1 前缀 + 1 后缀），稀有珠宝最多 4 条（2 前缀 + 2 后缀）
- 新角色有 3 颗固定示例珠宝；每轮战斗每击败 20 个敌人，自动获得 1 颗随机珠宝
- 在天赋星图中选择已激活的珠宝槽，再选珠宝镶嵌；可替换、取下及在槽位之间移动
- 珠宝的伤害、生命、魔力、护盾、攻速、移速与回复词缀立即影响真实战斗属性
- 每颗珠宝拥有独立标识，只能处在背包或一个槽位中；总藏品上限 64，满时不再发放奖励，已有珠宝不会被覆盖
- 可在珠宝详情中丢弃背包里的珠宝；需要再次确认，丢弃后不可恢复，已镶嵌珠宝不能直接丢弃
- 珠宝与天赋共同保存；打开任意构筑面板都会暂停战斗

本阶段仅实现基础魔法/稀有属性珠宝。尚未实现星团、永恒、半径、唯一珠宝或通货制作。

### 格子背包

- 12 × 8 格共享背包：武器占 1 × 3 格，护甲占 2 × 3 格，饰品和珠宝占 1 格
- 装备槽、背包与物品详情在同一界面；使用原创几何图标区分物品
- 拖动物品可自由摆放；拖到正确装备槽穿戴，已装备物品可拖回背包
- 重叠、越界和放错装备槽会被拒绝，不改变现有物品
- 点击物品查看词缀和尺寸；也可使用按钮穿戴/卸下，以及一键整理
- 取下珠宝、退回天赋槽及重置时统一回到背包；必要时自动整理空间，保留所有物品
- 背包布局随构筑保存；旧版拥有的装备会自动安置

### 已有玩法

- WASD / 方向键移动，平面竞技场，三种追击敌人与随时间增强的波次
- 自动锁敌射击、鼠标瞄准、穿透、减速、范围伤害、击退与连锁闪电
- 生命、魔力与能量护盾 HUD；护盾优先承伤，受击 4 秒后开始回复
- 8 种主动技能：龙卷、飞弹、冰霜、新星、冲刺、结界、陨星、闪电；通过面板配置 1—5 技能槽
- 9 件初始装备、武器 / 护甲 / 饰品槽，装备替换会立即更新属性
- 补给、伤害数字、暂停、死亡与重试、本地构筑成长存档
- 自带中文字体，不依赖 Windows 安装中文字体

这是未签名开发原型。原创二维图形由程序绘制，已有基础随机装备奖励；尚未加入最终角色动画、音效、刷图关卡、辅助技能宝石或联机。

## 快速开始

## 存档与旧版升级

Windows 默认位置：`%APPDATA%\Godot\app_userdata\godot游戏仓\build_save.json`。

- 保存装备、技能、等级、经验、天赋路线、珠宝实例与镶嵌位置；不保存当前战斗状态
- v0.1 存档可读取：保留装备、技能与成长，把旧天赋的全部已花点数退回，并发放基础珠宝
- 首次保存迁移结果前自动保留原始 `build_save.json.v1-backup.json`；备份失败会停止写入并保留旧文件
- v0.3 使用存档格式 v3；v1 / v2 均可升级。v2 保留原构筑，补发三件机制装备，不强制替换已有装备与技能
- 升级覆盖前保留原始 `.v1-backup.json` 或 `.v2-backup.json`；冲突或备份失败会停止覆盖
- v0.5 使用存档格式 v4；v3 迁移保留原装备、天赋、技能和珠宝，新增随机装备实例表。原字节备份为 `.v3-backup.json`；错误实例拒绝整份加载
- v0.6 使用存档格式 v5，按技能 ID 保存辅助；v4 升级在首次原路径覆盖前保存 `.v4-backup.json`，不改原装备掷值
- v0.7 使用存档格式v6，旧物品语义和掷值不变；v5覆盖前保留 `.v5-backup.json`。无法读取的已有文件进入写入保护，先备份原文，再使用兼容版本或恢复有效备份
- v0.9使用v7格式，v6首次覆盖前保存 `.v6-backup.json`；寻枝资格与分配/交换/读档使用相同分析器，新档与升级均不补发特殊珠宝
- v0.11使用v8格式，v7首次覆盖前保存 `.v7-backup.json`；旧装备/珠宝/辅助/天赋与掷值保持，不补发灰烬皮甲，旧版词汇不接受新防御物品注入
- v0.14使用v10格式，v9首次覆盖前保存 `.v9-backup.json`；装备词汇仍为9，新辅助仅v10允许，旧版本注入和未来文件继续拒绝
- v0.13使用v9格式，v8首次覆盖前保存 `.v8-backup.json`；新弓只新增词汇资格，武器配置派生自合法实例而不另行保存，旧数据保持且不补发新弓
- 新存档不能由旧版程序读取；如需回退，可在备份现有存档后恢复对应旧版备份
- 读取时验证点数、图连通性、珠宝词缀和唯一位置，拒绝损坏或越界数据，避免部分加载
- 写入使用临时文件后替换；构筑变化后与战斗中定期自动保存，存档不进入 Git

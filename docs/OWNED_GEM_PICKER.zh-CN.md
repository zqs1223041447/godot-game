# 点击空孔装配已有宝石

打开 **K 技能界面**，点击一个空的主动或辅助孔，选择行囊中的宝石即可装入。

- 主动孔只列出行囊中已有、能装入该孔的主动宝石。
- 辅助孔根据本行当前组合筛选，只列可装入的辅助。重复类型或不兼容的辅助不会列入；尚未装入主动宝石时先提示装主孔。
- 条目注明所在行囊页；悬停可查看描述和格子位置。相同名称的两颗宝石仍是两个独立实例。
- 没有候选时显示原因，不会创建、购买或赠送宝石。待安置区或其他技能行里的宝石不在此菜单内。
- 按Esc或点击菜单外取消；关掉K界面或构筑发生变化也会取消旧选择。

该入口只填空孔。替换已占用孔仍用原拖放；右键仍将宝石取回行囊。所有装配继续经过原物品移动与保存事务，使用原UID，不重掷、不复制，保存失败保持原状。现有冷却、技能效果、绑定和schema59不变。

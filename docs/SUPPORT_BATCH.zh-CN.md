# 辅助组合整批 · v0.19

本批一次接入16种原型辅助，覆盖当前8个主动技能。包括原有散束/凝束/贯穿、未正式发布候选中的广域，以及12种新选择；v0.18独立草稿没有发布，现统一进入这一批。不是照搬PoE完整宝石库。

## 组合有取舍

- 广域＋凝域：面积1.44×0.64=0.9216，统一开方后半径0.96；新星148.8、陨星105.6。命中×1.0625、魔力×1.44，冷却不变。单独凝域半径124/88；并非两槽越满就全面更强
- 节能＋疾咏：魔力×1.12、冷却×0.92；更频繁施放仍增加成本，utility效果量不变
- 连锁延展＋远链：最多7个不重复目标，包含首个；续跳286、首段仍600，主命中×0.72、魔力×1.495。原每目标伤害/附加效用递减继续生效
- 两种专注在龙卷同时使用：物理/火焰各×0.96，其他分量×0.64，魔力×1.3225；不会把相反惩罚吞掉或自动变成最佳配置
- 缓速冰霜速度390，原射程650和寿命1.7秒不变；抵达射程后只余约0.0333秒，无法为慢速偷偷延长返回行程。减速/返回/穿透和自然结束爆炸仍按原规则独立执行

图鉴逐项提供无辅助与单辅助的同源参数表，并列出所有合法双槽示例。范围图还比较中心、聚集、原边缘和外圈固定站位。每次命中、防御前/后分量与目标数分别表达，不称总DPS或必然清怪收益。

## 存档和运行边界

schema13仍为17字段，全部12个新ID从13接受；广域从12、贯穿从10接受。v11/v12文字夹具包含实际装备、特殊珠宝远程天赋、非零材料和revision；覆盖原BOM/CRLF字节备份、身份/掷值/位置/原辅助保持、旧版本注入新ID整档拒绝、未来记录路径写保护、加载使临时报价失效。没有删档或免费重置材料。

单次施放先冻结构筑、编译配方和分量，再统一支付魔力/冷却与发射。换装备、改辅助或交换技能栏只影响后续施放；当前目标防御仍在真正命中时读取。容量不够发射完整弹组时拒绝且不扣费。

尚未实现触发辅助、物理转换、持续伤害、完整异常系统、保留或更多槽位。本批不为没有实际消费者的条目添加可点选空壳。

# 冲刺与结界保留较长的剩余保护

此前，结界提供0.8秒保护后立即冲刺，会用冲刺的0.6秒直接覆盖剩余保护；开局1.5秒保护也会被这两种技能缩短。该行为与各技能的保护用途冲突。

现在成功施放时，保护剩余时间取当前剩余与本次技能时长的较大值。结界仍为0.8秒，冲刺仍为0.6秒；不同来源不相加，已流逝的时间不重置。结界后过0.1秒再冲刺保留0.7秒，过0.25秒后冲刺则获得0.6秒。

只改变这两处保护赋值。原移动与墙体碰撞、结界回盾、受伤充能等待、魔力、技能组冷却、输入和随机序列保持。无魔、冷却、阻塞等拒绝路径不获得或改变保护。

命中与燃烧仍走已有消费者。同步模拟tick开始时保存当前保护截止时间，再按时间片裁剪燃烧；技能输入发生在tick之间，因此无需新状态队列或修改燃烧时序。

这是源码修正，不增加宝石、存档schema或游戏版本号，也不重建无变化的F8资料。实际验证结果见 [定向记录](qa/v084-protection/README.md)。

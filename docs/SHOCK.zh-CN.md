# 感电命中构筑

感电辅助仅适配奥术飞弹、奥能新星和连锁闪电。它让主命中伤害乘0.80、魔耗乘1.20；目标实际损失护盾或生命，且本次结算有正值闪电分量、目标仍存活时，在结算后附加2秒感电。感电让后续命中承受伤害提高15%，不追溯施加它的那次命中。这些是本游戏初版可调预算，不宣称照搬其他游戏公式。

三技能通过相同规则生效；额外装备电伤、暴击或未安装该辅助都不会自动感电。独立到期爆炸不能施加状态，但作为后续命中可以受目标已有感电影响。感电不增加燃烧或其他持续扣伤；原火伤基数也不被这个承伤倍率再次放大。

真实命中先经过原命中判定、进攻乘区和暴击，再经过抗性与护甲。感电仅把已减免的每个命中分量乘1.15一次，然后沿原先护盾、生命顺序扣除。偷取仍依据实际损失，不从过量伤害生成回复。同目标不叠层、不传播；相同强度刷新到新命中的绝对截止时刻。

雷纹掠行体只有锁定地面的预警震击附加1秒感电。它仍有0.7秒预警、65范围与1.6秒恢复，可走开或利用实体墙；单击倍率从1.6降到1.4。其他电伤与普通接触攻击没有免费附加状态。目标身边的小暖金闪电折线表示当前感电，低特效仍保留。

感电只存在于当前战斗，不逐命中写存档。死亡、返城、完成地图、重开和切档清理对应状态。暂停冻结模拟时钟。原投射物近等时刻顺序保留；较早事件不能读取其未来才产生的状态，精确截止不再生效。生产模拟固定1/60秒，过期交错只保留必要的前一区间；整批先校验，越出保留历史窗口会在任何命中结算前拒绝，而不是部分结算。

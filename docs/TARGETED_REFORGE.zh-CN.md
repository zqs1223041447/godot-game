# 定向重铸初版合同

四个方向使用已有目录词族：暴击（全局几率或倍率）、攻击生命偷取、攻击魔力偷取、伤害。方向只保证至少一条合法匹配词缀，不保证最高阶、当前技能受益或比原装备更强。伤害含目录已有法术、攻击元素、投射物、三元素提高、限定攻击/法术附加与武器本地物伤；不含攻速或额外技能行。

- 魔法装备16校准碎片、稀有装备40；这是本游戏可调原型预算
- 稀有度、UID、底材、物品等级、背包位置保留；全部原词缀重新生成
- 先按真实目录、底材池、物品等级筛选，再从可完成合法前后缀/互斥组合的结果数中取样；保证词族按原阶级权重抽取，其余按原目录权重补齐
- 无合法目标或合法完整组合时，元数据禁用并说明；不创建随机结果或扣款
- 首次点击只取得权威费用/源装备报价，确认后以保存的句柄、完整快照、磁盘原字节戳校验并原子落盘
- 取消、重复确认、换选择、存档外改、余额不足和写盘失败不应用部分结果
- 正式/测试使用现有工匠与真实校准碎片物品；测试供应仍独立，无新钱包或地图门槛
- schema30不变；旧六工艺费用、种子规则、生成算法和返回形状保留

## 稳定接点

四个 operation 为 targeted_reforge_critical、targeted_reforge_life_leech、targeted_reforge_mana_leech、targeted_reforge_damage。原 crafting_quote(operation, uid, path) 和 execute_crafting(handle, source_instance) 不加参数。新规则版本为 original-targeted-reforge-v1-affix27，operation 参与种子规则名称与句柄授权。

crafting_operations 返回的四新项额外含 targeted=true、target_id、target_label；cost仍为 calibration_shard整数映射。UI以下拉选方向加单个按钮显示，权威确认使用真实报价。旧六项元数据无新增字段。

当前暴击和双偷取适用于途镜坠、脉籽符、纹刻指环、织纹手套；其余底材若无对应真实词族则不可用。伤害方向在五种九槽扩展底材上不可用。完整清单由实时目录与报价决定。

# 牵引辅助

只支持奥能新星与陨星坠落，包括符印伏击保存的同技能。范围命中照常结算之后，把原190击退冲量改为朝本次真实爆发圆心的190冲量；原520/秒衰减、怪物移动、分离与墙体碰撞照常。与圆心重合时为零向量；保留原准入和致死命中后冲量赋值位置。

魔力消耗乘1.20，占用一个辅助槽，不增减伤害、冷却、爆发半径或伏击触发半径。没有持续吸附、瞬移、自动追踪、强制汇聚或新队列。仅看冲量且忽略离散步长与其他速度时，位移约为190²/(2×520)=34.7；实战受其他移动和地形影响。自心新星会把敌人拉近角色，也可能增加贴身风险。

`compiled.area_impulse_profile` 与 `snapshot.area_impulse_policy` 均为独立副本，字段 `enabled=true, impulse_speed=190.0, mana_multiplier=1.20, direction="toward_origin"`。伏击在放置时冻结该策略，触发以陷阱实际位置为圆心；之后换装、退款或拆卸辅助不改已放置策略。没有牵引时不增加空字段，原向外冲量表达式保持。

严格存档42→43迁移先验证旧词汇，再备份原字节，不赠宝石/碎片。正式商人4校准碎片，测试目录免费；旧26种里程碑奖励顺序、source41与装备39政策保持。此辅助不解锁源树击退或陷阱专属效果。

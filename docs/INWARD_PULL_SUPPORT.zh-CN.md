# 牵引辅助

支持奥能新星、陨星坠落、裂刃斩与冰霜脉冲。新星与陨星保留原范围命中流程，将原190向外冲量反转为朝真实爆发圆心的190冲量；符印伏击使用已放置符印的位置。

裂刃斩只对原扇区、距离、视线与攻击命中判定通过且结算成功的目标施加牵引，原点为本次施放时角色位置。闪避、出生保护和遮挡目标不牵引。普通裂刃仍是前方180度，搭配环斩才覆盖360度。不改变攻击、近战、范围与命中标签，不额外掷命中或暴击。

冰霜脉冲在原投射物主命中结算成功后，以190初速拉向发射时角色的脚下位置，替换原45向外冲量。在途冰弹保留该原点与本次策略，不跟随之后的角色位置或卸装变化；冰缓、霜锁、弹数、穿透和独立爆炸原结果保持。

魔力消耗乘1.20，占一个辅助槽；牵引自身不增减伤害、冷却或范围。沿用原520/秒衰减、怪物移动、分离与墙体碰撞；与中心重合时为零向量。裂刃重合目标仍沿原朝向判定命中；重复成功命中覆盖原冲量，不叠加速度。没有持续吸附、瞬移或强制汇聚，不保证拉到中心。仅看冲量且忽略离散步长与其他速度时，位移约为190²/(2×520)=34.7；实战受其他移动和地形影响。新星与裂刃会把敌人拉近角色，也增加贴身风险。

`compiled.area_impulse_profile` 与 `snapshot.area_impulse_policy` 均为独立副本，字段 `enabled=true, impulse_speed=190.0, mana_multiplier=1.20, direction="toward_origin"`。伏击在放置时冻结策略，之后换装、退款或拆卸辅助不改已有符印；裂刃拆卸辅助不撤销已施加的冲量。未装牵引时不增加空字段，原法术向外冲量保持，裂刃没有该牵引冲量。

正式宝石商人售价4校准碎片，按原报价／确认事务购买后入背包，再装入对应主动技能的辅助槽。测试目录的免费供应不作为正式获得路径。牵引最初随存档42→43迁移引入；本次冰霜扩展保持现行schema61，不赠宝石或碎片，不改变原里程碑奖励与源树消费者。

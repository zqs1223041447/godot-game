# 冰霜脉冲＋牵引

冰霜脉冲现在可装配既有牵引辅助。成功的冰弹主命中结算后，将原45向外冲量替换为朝发射时角色位置的190牵引初速。它让冰弹既能减速，也能把路径上的敌人拉向先前的施放位置；角色仍在原处时，也可能增加贴身风险。

代价是魔力×1.20，占用一个辅助槽。原伤害分量、弹数、穿透、射程、寿命、冰缓、霜锁规则和冷却保持；基础五冰弹仍为16→19.2魔力，穿透2次，冰缓3秒。独立爆炸继续结算原伤害，不附带冰缓或牵引。

每枚冰弹在发射时保留相同的角色脚下位置，不以偏移后的枪口、当前弹头或后来的角色位置作为牵引原点。发射后卸下辅助或移动角色，已有冰弹仍使用原点、伤害与牵引策略；后续新施放读取新装配。出生保护、死亡目标、墙体和原命中准入继续约束主命中。取消的冰弹不会继续造成命中或牵引。

牵引沿用520/秒的冲量衰减、敌人移动、分离与身体墙碰撞。重复命中覆盖冲量，不相加；目标与原点重合时为零。没有持续吸附、瞬移或保证拉到原点。牵引与霜锁是不同的控制：霜锁仍按原规则要求实际正值冰霜损伤，牵引消费原成功命中结算。

复用正式商人的原牵引宝石，售价4校准碎片，购买入包后装入冰霜辅助槽。schema61不变，不赠送宝石或碎片，不修改其他技能兼容关系。

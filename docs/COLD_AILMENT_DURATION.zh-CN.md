# 冰霜异常状态持续时间

v0.82 只开放源节点 **14209 / Cold Ailment Duration** 的完整原句 `20% increased Duration of Cold Ailments`，投影为 `cold_ailment_duration_increased = 0.20`。它延长现有冰霜脉冲的冰缓，以及霜锁辅助已经准入的冻结；不增加触发几率或新的异常来源。原文范围包含 Chilled、Frozen、Brittle，但本游戏没有 Brittle producer，此次也不新增。

## 合法入口与边界

节点只有这一条原始效果。职业起点免费，女巫和暗影刺客均可用 8 点完整前置路线取到；4 级预算为 8 点。

- 女巫：54447 → 57226 → 21678 → 32210 → 8948 → 27659 → 37671 → 27415 → 14209
- 暗影刺客：44683 → 38129 → 11334 → 15549 → 20546 → 21301 → 37671 → 27415 → 14209

只匹配上述精确 20% 原句。21460 的 `50% increased Duration of Cold Ailments` 仍未实装；冻结几率、冰缓效果、纯 Freeze Duration、条件效果、冰霜持续伤害及其他混合节点不会随之开放。完整节点和普通前置连通检查保持，不能穿越精通连接普通路线。

## 时长与施放快照

先完成既有辅助时长，再乘 `1 + cold_ailment_duration_increased`，每次施放只应用一次。

| 当前合法配置 | 未取 14209 | 已取 14209 |
| --- | ---: | ---: |
| 冰霜脉冲，无辅助 | 冰缓 3 秒 | 冰缓 3.6 秒 |
| 冰霜脉冲＋寒意延长 | 冰缓 4.5 秒 | 冰缓 5.4 秒 |
| 冰霜脉冲＋霜锁 | 冰缓 3 秒 | 冰缓 3.6 秒 |
| 霜锁冻结普通／魔法敌人 | 0.60 秒 | 0.72 秒 |
| 霜锁冻结稀有敌人 | 0.35 秒 | 0.42 秒 |
| 霜锁冻结首领 | 0.20 秒 | 0.24 秒 |

寒意延长的乘序为 `3 × 1.50 × 1.20 = 5.4`。只延长时长，冰缓移动倍率仍为 0.36，原 max 刷新和世界 delta 计时保持。Nova 的原生伤害是闪电，它既有的 0.6 秒通用 slow，包括伏击交付，均不是这里的冰霜异常 consumer，不获延长。

霜锁的主命中仍乘 0.75，魔力仍乘 1.20；与寒意延长互斥。只有已通过原出生与命中准入的 frost 主投射物，对存活敌人造成正的实际冰伤盾血损失才冻结。零损失、致死、DOT、独立爆炸、其他技能附加冰伤均不新增冻结资格。

所有稀有度解冻后的保护仍为 **1.50 秒**。例如已取节点的普通敌人在 0 秒成功冻结，到 0.72 秒解冻、2.22 秒可重新准入。冻结及保护期间同目标不续冻、不刷新、不叠加，多技能组共用怪物 ID；最多保留 100 个 ID，包含保护占位。死亡移除、场景切换清空和当帧命中边界不变。

属性进入独立施放快照；冻结策略和编译时长深拷贝。分配、退点、换装或拆石只影响之后的施放，不追改飞行中的 cast 或已经附加的状态。缺字段或显式零不增加空元数据，保留旧零来源编译包与运行结果；该精确对照由本批实际 Main 验证负责。

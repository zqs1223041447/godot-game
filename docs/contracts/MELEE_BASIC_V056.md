# v0.56 锻纹短刃普通近战攻击

基线为已发布v0.55 / `63d84b2db67feb51595caf786e0c311736f08a74`。本批是新武器行为，不是短刃旧射弹路径等价优化。

- 唯一触发条件：已装备真实合法 `forgeblade`。`basic` 保持原身份，不新增宝石、按键、槽位、词族或保存字段，schema仍34。
- `CombatData.BASIC_MELEE` 是唯一几何权威：`delivery="melee"`、`radius=60.0`、`half_angle=PI/4`（总角90°）、`max_targets=1`。
- 原物理分布、基础系数1.0、攻击附加效用1.0保持；新 `basic/direct` 使用 `[hit, attack, melee]`，不带area/projectile/spell/secondary。锻纹短刃W按既有本地公式加入一次，普通增伤/物理/近战/攻击/暴击与偷取再按各自既有范围处理。
- 普通近战不受投射速度、范围面积/范围伤害加成，不创建投射物，不占弹体容量，没有返回或飞行结束爆炸。旧已飞射弹仍读原冻结包；非短刃新施放继续原射弹编译和执行分支。
- 沿既有 `1/max(0.2, attack_speed)` 间隔。零魔力消耗；换装备不重置已进行间隔，成功起手按当时攻速冻结间隔，避免击杀升级反过来改变这次起手。
- 自动攻击只寻找真实范围内可见、存活且已过出生保护的目标，按中心距离、同距沿原数组顺序选择，再转向它。圈外不空挥、不设攻击间隔、不抽样。
- 手动左键沿现鼠标方向逻辑，可空挥；只有扇区内最近一个合法可见目标会接受原命中准入。每次实际起手（包括手动空挥）只冻结一次独立暴击roll、取得一个cast ID。闪避不重新选目标或补一次roll。
- 城镇/完成状态、暂停界面、死亡不发起近战；实际命中继续主场景 `_apply_damage_packet`，保留火焰/感电事件时钟、护甲、护盾→生命、真实损失偷取与合法死亡奖励。
- `get_basic_attack_profile()` 仅提供脱离内部数据的派送/几何标量。缓存复用现构筑签名；穿脱、改词缀、载入/切档及实际构筑变化使其失效。无目标时不复制完整施放快照，也不创建持续新对象池。
- 复用既有小半径cleave cue，只读取本次radius/angle/direction；无额外特效随机采样、不新增renderer。近战不增加表示实际投射物发射的 `total_shots`。

## 与裂刃斩的取舍

裂刃斩仍独立：280%系数/附加效用、95半径/180°、多目标、12魔力/1.4秒冷却和既有辅助。短刃普攻是免费单目标近战，名义默认1.7次/秒（实际帧计时沿旧逻辑），两种攻击可以并行，承认贴身总输出增加。

固定B18且不计职业属性时，白刀普通近战原始物理22、双T3本地顶31；默认20力量再提高4%，对应22.88和32.24。比较仅是单击与系数，不当实战DPS或Windows帧率结论。全局暴击/资源词缀照常全局，已有近战天赋自然作用新近战事件。

## 验收边界

一次集中短批验证旧非短刃完整编译/运行/RNG及旧飞箭冻结；新直接角色来源与标签防伪；真实UID切装/cache/保存往返；自动近/远/LOS/大体型边界/同距/单目标；手动方向/空挥；一次暴击roll、闪避/护盾生命/双偷取；满弹体仍可近战；攻击间隔、暂停/死亡/城镇门禁与裂刃独立冷却。

短刃的新攻击时刻、目标与命中方式会改变其整场结果，不承诺新短刃战斗的掉落RNG状态与v55射弹玩法逐字相同；掉落目录、奖励算法和其他武器原路径保持。不触及LUNA翻译、CanonicalPassivePanel或新技能系统，不跑600秒、历史全量或独立截图门槛。

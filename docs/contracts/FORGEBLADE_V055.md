# v0.55 锻纹短刃合同

基线：v0.54 / `5e442d98e82b248efc3a553fdf9bf95733929096`。这是本游戏可调原型预算，不是对其他游戏公式或最终平衡的宣称。

## 装备与有效词池

- 唯一新增底材 `forgeblade`，中文名锻纹短刃，武器位，1×3格；没有通用基伤、攻速或其他固有属性。本武器物理基底4。
- 新版本池 `forgeblade_v34`。三个前缀：`whetstone_edge`、`tempered_edge`、`deepwell`；三个后缀：`wellturn`、`global_critical_chance`、`global_critical_multiplier`。
- 本地平点T1/2/3为1–2 / 3–4 / 5–6；本地提高为10–15% / 16–22% / 23–30%。深汲最大魔力5–9 / 10–15 / 16–22；泉旋魔力回复提高3–5% / 6–9% / 10–14%；全局暴击几率提高15–20% / 21–30% / 31–40%；全局暴击倍率增加5–7 / 8–11 / 12–15个百分点。
- 六族均沿既有ilvl1/8/16门槛与100/60/30档权重。同族互斥，普通0条、魔法1–2且1前1后、稀有4–6且3前3后不变。
- 从ilvl1起，合法族集合数：普通1；魔法1条6、2条9；稀有4条15、5条6、6条1。不同档/掷值另计；不靠无实际作用词缀补足稀有数量。
- 两个本地族与两个全局暴击族仅增加这个新底材的资格；旧底材的资格、旧词池的顺序和数值不变。旧目录记录尽量作为冻结定义保留，版本扩展从独立配置派生。

## 唯一本地消费者

`W=(4+本武器附加物理)×(1+本武器物理提高)`。W只给 `cleave/direct` 的 `hit+attack+melee+area` 事件，贡献为 `W×既有技能基础系数2.8`；不增加技能之外的外加伤害，不作为全局increased再次进入解析器。

原有B、外加点伤、攻击/近战/物理/范围increased、暴击、护甲、护盾→生命、基于实际损失的偷取继续既有路径。本地W在施放时冻结，换装不重解释冻结包。无新武器或白蜡长弓的旧包保持原值与字段；长弓仍只增强普攻和龙卷箭体，短刃不增强这些载体、法术或独立爆炸。

这里的“不增强其他技能”仅指本地W。短刃上的全局暴击和资源词缀按原全局范围正常作用，不能人为缩成近战专属。

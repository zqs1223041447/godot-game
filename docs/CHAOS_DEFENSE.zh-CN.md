# 混沌防御与蚀影巡逻

本批把既有蚀影飞弹的混沌伤害与可选地图遭遇、可制作指环接成双向防御取舍。混沌抗性是独立属性，不属于三元素抗性、三元素最大抗性或元素穿透；当前仍先消耗护盾，再按已有魔力分担规则处理生命伤害。不加入绕盾或毒。

## 规则与供给

- 原始混沌抗性同类相加，有效值限制0–75%；当前只供应指环后缀，负原始值不会使本批规则产生负有效抗性
- 原刻纹指环新增“混沌抗性 +X%”后缀，物等1/8/16分别8–12%、13–18%、19–25%，权重100/60/30；占原后缀容量，与三抗及其他后缀竞争
- 只有ring_1/ring_2两个指环槽，双最高掷值为50%。75%是规则上限，不能当作当前装备必可达到的数值
- 词汇51新增build_nine_slot_v51；canonical_v51只替换原30%九槽池入口。自然新装备分布会变化；显式旧池、旧词汇及已生成装备保持原结果。主动制作沿当前池，取消或失败仍不改变物品/材料
- 存档50→51先严格验证并备份旧原字节，只开放新词汇，不赠送物品、点数或材料；天赋来源政策仍49

## 可选遭遇

新增“蚀影巡逻”，只在地图装置明确选择时生效，最低波级5、沿用一个特殊词缀名额与正式完成奖励+2碎片；测试模式没有奖励加成。正式断垣/晴泉/银杏II、旧庭III开始满足波级门槛。

原可替换重壳体名额变为蚀影守卫，保留原稀有度、机制、位置、出生保护、谱系与奖励资格；数量取决于原编排，不为保证出现额外创建怪物；不替换灰烬守卫、裂殖/孵化模板、首领或后代。全部初始怪物仍在入图时生成，警戒/唤醒、墙体视线、冻结暂停局部动作时钟复用现规则。

守卫保留重壳体生命、移动和体积，具有25%混沌抗性。锁定玩家起手位置的圆形攻击：前摇1秒、半径90、恢复1.8秒（沿原攻速规则）、伤害系数0.8、触发距离150；纯混沌命中，没有新异常状态。

无机制增幅普通重壳体的静态伤害例子：波级5的基数20.8×0.8=16.64，波级10的24.3×0.8=19.44；25%混抗后分别12.48/14.58，双环50%后8.32/9.72。实际稀有度、源机制和地图增伤仍按既有阶段作用，以上不是DPS或长期平衡结论。守卫25%混抗使蚀影的混沌分量承伤为原来的75%，其他原生/附加类型分别使用各自防御。

没有新逐帧扫描、状态队列或并行成长体系。新巡逻未选、新混抗来源未装备时保留旧战斗路径；当前池的新随机装备结果是有意内容变化，不能泛称新旧游戏所有随机结果等价。

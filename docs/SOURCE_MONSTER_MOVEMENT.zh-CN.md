# v0.74 单条源移动属性与怪物疾行

本批只增加 `source_gale_stride`。它精确绑定固定来源节点 `63417` 的 `stat_index = 1`（从0计数），原始行是 `4% increased Movement Speed`。怪物与玩家经同一个当前 `SourceTreeRuntime.line_effect` 获得 `move_speed_increased` 类型化属性，生产对象系数为 `1.0`。这条绑定不授予该节点另一条护甲属性、整个节点、升华资格或任何其他源基石。

## 当前与历史

23条历史机制定义及别名保持；第24条新定义通过 `MechanicRegistry` 供玩家与怪物共同请求。旧 `gale_stride` 仍为固定 `move_speed +3.12`，沿用原固定参考投影，不改名、不迁移、不用新的百分比重释旧数据。

旧 `AFFIX_POOL` 与 `ordinary_roll` 保留。`CURRENT_AFFIX_POOL` 只在相同疾行位置换入 `source_gale_stride`，新 `ordinary_roll_current` 沿用原抽签后换ID，池数量、次序、稀有度、抽签次数与RNG状态保持。当前Main普通入场和当前地图据点显式选择新入口；旧帮助函数继续默认历史政策。没有新奖励、经验或存档物品。

## 速度与缓存

当前怪物速度按下式在出生时计算一次，之后才接受既有地图倍率：

`（物种速度 + 波次速度 + 其他固定速度）×（1 + move_speed_increased）`

源适配器读取实际来源身份、节点/行索引和原始行，调用当前执行政策的解析器；仅允许一条非负、有限的移动速度提高授予。缓存键包括来源身份、原始行与执行政策。错误来源或不支持的效果拒绝整条授予，不回退到旧缓存或抄写百分比。怪物保留出生时的源授予快照，没有逐帧源树解析。

## F8与保全

F8明确标示23条“历史机制定义”和唯一“当前单条源绑定”，分别保留旧固定投影与当前词条入口。原怪物模板和所有历史技能、构筑、预算示例保持原值；当前自然选择的变化单列在新规则卡中，不能据此声称所有源基石已共享。

存档结构仍为47，装备词汇仍为46，源执行政策仍为45。本批无新美术、字体、图鉴图、UI布局或包产物。验证记录见 [v074 F8资料验证](qa/v074-reference/README.md)。

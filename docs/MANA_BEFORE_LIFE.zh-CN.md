# v0.58 心灵升华与魔力先承伤

本批从 v0.57 `3718d74691f3a7f9e2280fc26419c093b26ee4ac` 接入源关键天赋 **34098 心灵升华（Mind Over Matter）**。原始源句 `40% of Damage is taken from Mana before Life`、节点 ID、图结构及源版本 3.29.1 保持。源 stat 为 `damage_taken_from_mana_before_life`，值为比例小数 0.40。

## 资源结算

1. 命中沿原护甲、抗性、感电命中倍率结算；燃烧沿原火抗结算
2. 护盾先吸收防御后的损伤
3. 剩余损伤的 40% 请求由当前魔力支付，实际支出不超过当前魔力
4. 剩余部分扣生命；魔力不足产生的差额同样落到生命，超过生命的部分单列过量伤害

| 防御后损伤 | 初始盾 / 魔 / 血 | 盾支出 | 魔力支出 | 生命扣减 | 过量 |
|---|---|---|---|---|---|
| 100 | 0 / 100 / 200 | 0 | 40 | 60 | 0 |
| 100 | 0 / 10 / 200 | 0 | 10 | 90 | 0 |
| 100 | 30 / 100 / 200 | 30 | 28 | 42 | 0 |
| 100 | 100 / 100 / 200 | 100 | 0 | 0 | 0 |
| 100 | 0 / 0 / 200 | 0 | 0 | 100 | 0 |
| 100 | 0 / 10 / 20 | 0 | 10 | 20 | 70 |

以上每行均为独立初始状态，命中与燃烧直接使用同一生产资源结算规则；它们是固定输入的静态资源预算，不是实战 DPS。实际导出值见 [F8 图鉴](reference/index.html#rules-mana_guard) 与 [运行时目录](reference/catalog.json) 的 `mana_guard`。

魔力仍是施法、药剂、再生与偷取使用的同一个池。该效果不即时返还魔力、不提供免费施法。`mana_spent` 和 `remaining_mana` 独立记录，不混入 `health_lost` 或 `shield_spent`；现有浮字、偷取与命中归属保持原定义。闪避、免疫或非法输入不能半扣资源，致死状态不会因此复活。

## 权威来源与旧行为

`Defense.mana_guard_profile(stats)` 验证并返回 `{ok, reason, enabled, fraction}`，`CanonicalGameState.get_mana_guard_profile()` 直接使用该结果。命中与燃烧共享 `Defense.settle_with_mana`，在原伤害与资源验证之后验证启用的魔力输入。旧入口仅在末尾追加可选参数。

缺省比例或显式数字 0 保持旧返回字段与完整 Variant 字节，不凭空新增魔力字段。新 stat 默认值为 0；这是构筑派生统计的新键，不等同于旧统计字典仍逐字节一致。旧战斗配方和已飞行快照不加入这一防御字段。

图鉴所有示例均由 GDScript 调用实际源执行器、角色模型和防御消费者导出。Python 只渲染导出结果，不重新实现结算公式。图鉴提供的完整构筑候选通过当前 validator；这与迁移集中测试中的逐点分配证据分别记录，不把图路径统计冒充交互分配测试。

## 源树边界

本批唯一新增完整普通节点为 34098，七职业可达普通节点由 688 增至 689。女巫与圣堂武僧最短受支持路线各花 7 点，贵族 11 点；起点免费，点数预算按现有等级规则。其他职业及逐节点路径在图鉴规则卡中列出。这些路线分别成立，不代表可同时分配全部路线。

外图节点 42144 的 8% 与 922 的 10% 同族句可单独解析执行，但它们各自的其他效果仍未实现，整节点保持部分执行和不可分配。没有新增精通、升华授点、生命/魔力 Recoup、条件分摊、召唤物分摊或怪物魔力池。

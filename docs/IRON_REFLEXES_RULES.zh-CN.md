# 铁反射（闪转甲）（Iron Reflexes）

v0.64 接通固定源树 3.29.1 的基石 10661。完整源句为：

> Converts all Evasion Rating to Armour. Dexterity provides no bonus to Evasion Rating

原句、节点身份、图结构保持。只认完整效果，含其他未实现效果的混合节点仍不可分配。

## 转换与来源

A0、E0 是角色基础、已装备物品、珠宝及天赋的原始固定护甲与闪避之和；IA、IE 是对应提高比例，IE 不含敏捷。H 只统计同一原始词句同时提供两种提高的部分。

- 最终护甲：A0 × (1 + IA) + E0 × (1 + IA + IE − H)
- 转换贡献：E0 × (1 + IA + IE − H)，已经计入最终护甲
- 最终闪避：0

例如源节点 35568 的同一句护甲与闪避各提高 6%，在转换部分只计一次。两个不同原句即使数值同为 6% 也各自生效，不能以两个全局总量的较小值作为 H。当前装备、珠宝只供固定评级；将来引入提高来源，须保留来源边界后再接入。

敏捷继续每点提供 2 命中，之后仍应用命中提高；只取消敏捷提高闪避的效果。未分配时继续沿原来的护甲和闪避公式计算，统计字典不新增转换字段。

## 合法装备与天赋预算

F8 的数值由完整验证后的 CanonicalGameState 导出，读取 get_stats 与 get_defense_conversion_profile，网页不重复计算。实际例子保留其余默认装备和沿途全部属性：

| 构筑 | 等级 / 点数 | A0 / E0 | IA / IE / H | 分配后护甲 / 转换贡献 |
|---|---|---|---|---|
| 双防御胸甲，决斗者路线 | 8 / 12 | 120 / 465 | 0 / 0 / 0 | 585 / 465 |
| 同胸甲，加 24377、35568 分支 | 10 / 14 | 120 / 465 | 6% / 6% / 6% | 620.1 / 492.9 |
| 旧生命三抗胸甲，同分支 | 10 / 14 | 0 / 15 | 6% / 6% / 6% | 15.9 / 15.9 |

双防御胸甲使用现有灰烬皮甲及合法 T3 六词：ironhide、mistweave、rootwell、emberward、rimeward、stormward。两条固定防御分别为 120 护甲、450 闪避，角色另有基础闪避 15。旧胸甲为 rootwell 与三抗的合法四词物品。稀有物品仍须 4–6 词、最多三个前缀和三个后缀；这不是掉落保证，也不赠送该装备。

双防御占两条前缀，剩余一条在生命、魔力、护盾之间选择；三抗占满后缀。新基石没有取消这些装备取舍，也没有新增词族或掉落池。

决斗者主路线为 50986 → 39725 → 63649 → 49806 → 6580 → 19711 → 20010 → 23471 → 5237 → 6363 → 29937 → 8544 → 10661。分支清单是附加分配节点，不将两条分支画成一条连续边。F8 各行都比较同一合法构筑分配最后一点前后；未点时还剩一点。

## 命中、防御与资源

转换后的护甲继续进入既有按物理命中大小计算的减伤公式及 90% 上限。元素命中与燃烧不会因护甲增加而减伤。攻击依旧通过既有命中规则，闪避为零会失去原有躲避机会；因此护甲数值提高不能直接称为总体生存率提高。

F8 用同一真实角色比较 20、100、500 物理命中、各 100 三元素命中和 100 原始燃烧。示例将当前护盾设为零、生命设为 10000，只比较单次防御结算；保留实际抗性，不把命中概率乘成实战 DPS，也不宣称平均存活时间。

分配、退款和换装仅重算当前派生值，不自动补生命、护盾或魔力，不重置命中熵。失败事务须保留构筑、缓存及磁盘原字节。C 页的“转换贡献已计入”是解释最终护甲来源，不能再次相加。没有新增战斗扫描、计时器或随机数。

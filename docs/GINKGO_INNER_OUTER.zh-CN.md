# 银杏回廊：内圈后外环

本次只调整当前探索地图 `ginkgo_arcade` 的首领攻击 `ginkgo_shelter_slam`。首领起手后固定同一圆心，先打内圈，再打外环；玩家可先退后进，也可继续远离。

## 时序、伤害与安全区域

- 启动距离仍为 240。圆心在起手时取首领位置，第二段不会跟随首领或玩家重新锁点。
- 第一段完整预警 1.4 秒，结算半径 130 的实心圆，伤害包为起手冻结的当前首领接触分量 × 0.6。
- 第一段后再给完整 1.0 秒预警，结算内半径 130、外半径 240 的空心环，同一份冻结接触分量 × 0.6。
- 两段均结算完才进入恢复。基础恢复 1.9 秒，沿既有当前攻速缩放与上下限；攻速不压缩两段完整预警。
- 两段合计 1.2 倍只是防御前名义预算。站位、墙体视线、已有免疫、攻击闪避、护盾和减伤可能阻止或减少实际损伤，不承诺两段都命中或扣除固定生命。

令 `d` 为角色中心距锁定圆心的距离，`r` 为角色身体半径：第一段在 `d ≤ 130 + r` 时接触命中。第二段在 `d ≤ 240 + r` 且 `d + r ≥ 130` 时与环相交；边界接触也算命中。第二段完全处于内侧安全区要求 `d + r < 130`，完全退出外侧要求 `d > 240 + r`。

当前 `Main.PLAYER_RADIUS = 15`，所以第一段完全避开要 `d > 145`；第二段完全避开要 `d < 115` 或 `d > 255`。距离恰为 115 或 255 都会接触外环，不能只看角色中心是否在图形内。第一段结束后可从外面进入内侧安全区，但必须在第二段结算前让整个身体进入。

## 运行与视觉合同

第一段显示实心圆预警；第二段显示空心环，内侧保持可辨认的安全区。两段共用起手圆心与冻结伤害包。事件 `profile_id` 和伤害包 `skill_id` 为 `ginkgo_inner_outer`，`balance_version` 为 `original-ginkgo-inner-outer-v1`；事件 schema 保持原版。

冻结暂停来源的局部动作时钟，恢复后接续尚未走完的预警。来源死亡、移除或重新进入出生保护时取消；玩家死亡、重开、返城也沿共享清理路径取消。整段攻击期间不额外叠加首领的贴身接触攻击。墙体仍通过现有结算视线检查阻挡命中。

本次不调整地图布局、路线、入口净距、怪物编排或掉落。布局局部首领锚点仍为 `(3180, 320)`；当前地图世界坐标会加上边界原点，因此既有目录中的首领位置为 `(3222, 424)`。此坐标区分不代表移动了出生点。入图仍为 36 个普通根怪加 1 首领，首领仍走原有限 4 后代规则，入口净距仍为 850。

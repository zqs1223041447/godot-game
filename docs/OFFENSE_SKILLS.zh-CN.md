# 近身物理与混沌命中闭环（v0.24在制）

本批补已可分配的近战物理与混沌增伤消费者。不是新增毒、持续伤害、伤害转换或新武器本地公式。图标由root原创生成、实看后交付，PNG原字节保留并以512px/mipmap导入，真实透明背景，现有UI布局不变。

- `cleave` 裂刃斩：280%基础倍率/附加效用，12魔力，1.4秒冷却，面前180度扇区，半径95。标签hit/attack/melee/area，按真实命中与护甲结算。可链接广域、凝域、物理专注、节能、疾咏。攻击速度沿现有语义仅改变普攻，不冒称缩短本技能固定冷却；白蜡长弓本地W仍只给旧有普攻/龙卷消费者。
- `shade_bolt` 蚀影飞弹：1枚，240%基础混沌法术命中/附加效用，10魔力，1.2秒冷却，速度620，穿透0，减速0。装备可附加已支持的其他法术伤害分量，固有分量为混沌。可链接散射、聚能、贯穿、节能、疾咏、疾速投射、缓速强击；继承现有装备授予的返回/自然结束独立火爆炸。没有毒或DoT。

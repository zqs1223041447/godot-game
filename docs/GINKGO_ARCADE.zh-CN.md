# 银杏回廊：第四地图内容合同

开发候选，稳定地图 ID 为 `ginkgo_arcade`，首领动作为 `ginkgo_shelter_slam`（回廊震击）。这是既有地图、据点与预警系统的内容扩展；数值属于本游戏原型预算，不是实战平衡结论。

## 玩法与地图成长

- 正式 I／II／III 档分别采用第 3／6／10 波强度，入场消耗 0／4／8 校准碎片，基础完成奖励 4／8／12 碎片
- 普通词缀每项完成奖 +1，最多两项；特殊词缀每项 +2，最多一项。既有理论加奖上限为 +4，但 I 档第 3 波未达特殊词缀门槛，实际最多 +2；II／III 档最多 +4
- 本图 I 档初始开放，完成本图前一档才解锁下一档；其他地图进度不代替本图解锁。独立测试地图沿用免费制作、固定第 6 波，不增加正式完成奖励
- 西叶、北廊、东荫三个据点各有 12 个普通根怪，共 36 个。可任意顺序激活，也可让三组同时在场；不减怪、不拆组，不要求清完前一组
- 靠近或穿过木牌触发区域才请求整组入场。保留半径 64 的触发区、距玩家至少 230 的出生安全距离、0.6 秒出生提示与既有容量门槛；容量不足整组等待
- 全部 36 个普通根怪死亡后开放首领入口。首领及死亡后代清完才完成；返城后通过原领奖事务领取冻结的完成奖，待领奖时不能再次入图，重复完成或领奖不重复结算
- 合法根怪沿用原经验、装备、宝石与药剂供给，后代不增加奖励。没有新掉落、奖励倍率或雾羽名额；雾羽仍只在晴泉台地原有范围内出现

## 地形与编排的唯一来源

中央实体花圃和两座基台共同形成内侧通路及外侧绕行路线。角色、怪物、冲刺、击退、弹体和视线统一读取 `MapGeometry` 的三个实体矩形；视觉不得扩大或缩小阻挡。贯穿与返回弹体仍碰墙，碰墙终止不触发自然到期爆炸、分裂或返回；范围命中、连锁与敌预警保留墙体视线检查。

`MapCampLayout` 是入口、据点阵形、木牌和首领位置的唯一来源。东荫据点已作局部安全调整，以满足全部触发区的出生距离；文档不另存一套坐标。F8 新图平面图从同源快照读取矩形、完整阵形与触发圆，绘制时只减去世界原点，不重新缩放或推算布局。

据点基础物种编排读取 `scripts/world/ginkgo_roster_rules.gd`。先完成原普通抽签，再按本图据点及组内序号映射基础物种，保留原稀有度、机制、固定灰烬与死亡繁衍名额。西叶偏掠行混合，北廊偏重壳与霜纹，东荫偏重壳与雷纹；霜纹／雷纹仍受第 4／5 波门槛约束，门槛前回退为基础物种，巡逻特殊词缀保持最终优先权。映射不消耗新随机数；旧三图的 profile、layout、seed 与 RNG 行为不被新图分支改写。

## 回廊震击

首领在距离 240 内且视线可达时起手。圆心锁定首领起手位置（`self_at_start`），攻击半径 240，完整预警 1.4 秒；只结算一响，防御前各伤害分量为本图当前首领接触分量的 1.2 倍。动作替代原接触攻击，不增加额外燃烧、冻结、感电或追踪落点。

看到预警后，可把身体完全移出圆圈，或移动到实体障碍后阻断结算视线。圆圈表示攻击区域，角色半径仍参与边缘相交；仅让角色中心刚好跨过圆周不足以保证脱离。预警使用既有单响调度与 LOS，不加入新战斗时钟。

恢复基底为 1.9 秒，实际恢复由既有策略按首领当前攻击速度缩放，并遵守原上下限；1.9 秒不是所有词缀状态下的固定恢复。攻速不缩短 1.4 秒预警。攻击起手后冻结本次时序与伤害，冻结异常暂停并续接同一个动作；击退仍可推动首领，但不拖动已锁定圆心。来源死亡、玩家死亡、返城或重开沿原规则取消动作。

视觉沿 `world_geometry().walls`、`landmarks` 和 `telegraph_visual_states()`；新图标识为 `obstacle_style=ginkgo_planters`，预警标识为 `visual_pattern=ginkgo_shelter_slam`。地形与预警渲染均不拥有另一套碰撞或伤害参数。

## 存档与版本边界

当前 schema 为 50。先严格验证冻结的 schema49，再保留旧原始文件的字节备份；迁移只改变版本，并增加 `journey.best_tiers.ginkgo_arcade=0`。旧三图进度、在途记录、待领奖励、UID、装备、宝石、天赋、货币与奖励序列保持。schema49 不得预先注入新图字段或新图运行记录。

源天赋政策保持 49，装备词汇保持 46；本图没有新源天赋消费者，因此不重新生成完整源树 coverage。新资料页通过窄片段加入新图，保留旧 JSON 数值 token、旧图卡、源 coverage 和资料图片原字节；当前版本标签差异单独记录。

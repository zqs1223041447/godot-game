# 视觉系统与 2K 可读性

## v0.11火系遭遇增量

新增灰石肩甲、暖皮革与护火符印的灰烬守卫，保留重壳体22单位判定与俯视大小；灰烬皮甲沿用真实装备绘制路径。名牌和标记从有效火抗读取，不硬编码模板数值，仍最多8个完整名牌并避让。38张运行图标可供离线图鉴复用。

验收：actor360项、21种装备轮廓/1960图元边界、火抗名牌161项；原生720p最大UI110%/字体120%的火抗摘要无横向溢出，2K实际入场/施法/受击与穿戴画面可读。本版没有重排控件。用户后续明确批准的UI参考另作为下一版材质与控件风格改进，不混入本次冻结。

## v0.5 实现边界

保持原有 2D 俯视战斗与 1280 × 720 世界坐标，不改变碰撞、范围、投射物寿命或伤害。角色、怪物、竞技场和技能标识为原创程序化矢量绘制，不依赖第三方商业游戏美术资产。本轮是可继续替换/扩展的视觉基础，不是 3D 模型或完整骨骼动作系统。

- 暗石、氧化青绿与黄铜的界面语言；中文动态字体、高对比按钮和键盘焦点
- 分层兜帽/披风/肩甲角色；法杖、刃、长弓随当前装备变化
- 六足巡游体、翼刃掠行体、重甲重壳体的独立轮廓与轻量动画
- 魔法菱形、稀有冠形、首领三角徽记，加上名称与颜色，稀有度不只靠颜色辨别；三颗小菱形继续表示死亡分裂
- 飞弹轨道、冰霜晶体与龙卷箭区分；返回箭保留紫色和双折线提示；环形效果保留范围边界
- 原创矢量技能图标与状态热键栏；真实长弓、杖、袍/披风和珠宝图标

## 显示设置

Esc → 显示设置。立即生效，并独立写入 `user://visual_settings.cfg`：

| 项目 | 取值 |
|---|---|
| 界面缩放 | 90%、100%、110% |
| 字体大小 | 100%、110%、120% |
| 特效强度 | 低、中、高 |
| 伤害/回复数字 | 开关 |
| 角色装饰动画 | 开关 |

Godot `canvas_items` 对物理窗口进行清晰重绘；HUD 根节点的独立缩放改变 UI 尺寸，不改变世界位置或逻辑。最大字号/缩放下，长面板保留滚动；装备词缀另有内层滚动区域。放大 HUD 时隐藏右下角辅助提示，完整操作仍可从暂停菜单查看。设置读取会将非法值还原或限制在支持的范围。

低特效仅减少装饰粒子和辉光，攻击载体、范围边界、稀有度和分裂标记仍显示。字体缩放不重复累乘。

## 模块与扩展

- `scripts/visuals/arena_visuals.gd`：只读战斗数据并渲染，不产生游戏事件
- `scripts/visuals/visual_settings.gd`：显示偏好及独立持久化
- `scripts/visuals/visual_theme.gd`：主题、样式、字体缩放
- `scripts/visuals/skill_emblem.gd`：技能矢量图标
- `scripts/game_hud.gd`：独立 HUD 缩放、设置入口及状态显示

随机装备详情使用统一 `get_item_definition`，展示等级、稀有度、总属性、前后缀与 T1/T2/T3；装备栏使用底材名避免长稀有名称被截断。丢弃动作先显示单独确认窗口；取消不改变物品，确认时再次由数据模型检查目标仍可丢弃。

## 验证

- `tests/visual_settings_test.gd`：199 项设置往返、损坏值处理、9 种 UI/字体组合 × 7 个面板、无水平溢出、坐标独立、六词缀装备交互检查
- `tests/visual_capture.gd`：真实图形窗口生成 1280×720、1920×1080、2560×1440 与 90/100/110% UI 的截图，最大 UI 同时使用 120% 字号；补充投射物生命周期截图
- 截图目录由 `GODOT_VISUAL_QA_DIR` 环境变量设置，默认 `user://visual-qa`；仅供开发验证
- 云端 Linux 原生 GUI 实测装备/卸下、六词缀滚动、取消/确认丢弃、设置下拉操作、Esc 关闭与重复打开

Linux 图形检查不等同于 Windows 实机检查。当前 Windows 发布包仍需在 Windows 上完成最终启动与 DPI 环境验收。

## v0.6：施法、命中与状态反馈

`combat_cues.gd` 是独立的短时视觉事件池：最多 96 个提示，持续时间 0.20—0.65 秒，只复制位置/方向/颜色/半径等值，不持有战斗对象，不消耗随机数，也不写构筑/伤害。仅在施放被接纳、真实命中、实际连锁或生命周期事件成立后发出提示。重试会清空；暂停与战斗时钟同步。

`combat_cue_renderer.gd` 将效果拆为地面层和前景层：

- 龙卷的旋弧、飞弹的菱形、冰霜的六臂施放符号
- 新星外圈先展示完整实际范围，内圈脉冲扩散；陨星为放射冲击与中心短时余烬
- 护盾六边结构；冲刺使用真实起点与经过边界裁剪后的终点
- 连锁闪电保留每条实际目标连线与末端标记，低特效也不再丢失路径
- 敌方生命命中为四向星芒，护盾命中为六边轮廓；玩家受伤为独立暖色括角，完全由护盾吸收时改为冷色
- 减速的六臂状态图标保留在怪物身侧，不依赖稀有度颜色；分裂、返回和死亡有不同提示

达到事件池上限时，新范围/目标/受伤提示优先于装饰性命中提示；装饰提示不能挤掉范围提示。核心投射物、怪物、护盾和状态绘制不受事件池容量控制。低效果仍保留所有核心形状，不加入全屏闪光。

补充验证：`combat_cues_test.gd` 1,032 项覆盖拷贝隔离、错误值、优先级/上限、寿命与压力；`combat_cues_integration_test.gd` 48 项覆盖被拒绝施放、连锁实际端点、实际伤害/吸收、完整 5 母箭/15 子箭返回/爆炸生命周期、随机数不变与重试清空。`visual_cues_capture.gd` 提供低/高效果图鉴，`visual_combat_capture.gd` 通过真实主场景渲染连锁、范围技能与辅助槽面板。

## v0.7：经典魔法世界材质统一

本轮遵循统一方向：有日光、冒险感和魔法感，避免阴暗压抑、科技/赛博、霓虹和大面积光污染。PoE 仅作为构筑游戏的设计参考；下列图形均为原创程序绘制。

**保留布局。** HUD、导航、技能栏、格子背包、天赋图和面板节点的锚点、位置、格子尺寸与操作结构不因换美术而改变；仍保留原有缩放与字号选项、键鼠操作和滚动。

- `fantasy_environment.gd`：明亮的风化石庭、不同宽度的石板、浅裂纹、苔痕、草边和不规则灌木。原来的同心圆准星式地面与科技网格移除；战斗边界和坐标不变
- `fantasy_actors.gd`：可见面孔的兜帽旅人、布料褶皱/皮革腰带/背包、木杖与旧金属武器；三种有机怪物轮廓与鹿角甲壳首领。白蓝金橙改为小徽记/名字，护盾和减速用清晰小标记，取消整圈霓虹环
- `equipment_art.gd`：19 种原创外形覆盖 9 固定装备、7 个普通底材与 3 珠宝基底。木纹、缠绕握柄、锻造刃面、布料缝线、旅行披风、宝石切面在 42px 格子和放大详情中保持一致；符木法器有独立木质符文头部
- `material_frame.gd`：皮革/木质底色、旧铜切角边框、细纹和小铆钉，取代圆角软件按钮。样式复制保留材质属性，焦点边框保持透明；资源条继续使用简洁平面填充
- `fantasy_palette.gd` 与 `skill_emblem.gd`：技能为刻在石/铜令牌上的元素图案；展示色独立映射，不更改技能类型、配方或伤害
- 火焰爆炸改为短时不规则火舌及少量真实半径端点，不再叠加钟面式圆环；冰、风、闪电、护盾各保留特征，低特效模式仍能识别路径与状态。所有特效仍受原事件池上限控制，地面特效画在角色和怪物下方

独立检查包括：354 个角色断言 / 174 个不变性样本 / 696 次绘制回调；装备覆盖 29 条输入记录、9 种目标尺寸、1,730 项图元边界检查；153 项材质样式复制、透明焦点与边界检查。纯绘制不写人物、怪物、装备、存档或随机数状态。

`visual_stress_capture.gd` 使用真实主场景在 2560×1440 下同时绘制 55 怪物、180 投射物和 96 提示，检查高/低特效时轮廓与战场可见性。这是可读性和容量验收，不是 Windows 硬件帧率承诺。新法器、分类伤害预览和字号上限还应随当前主分支重复原生 UI 回归。

## v0.8：宽视距与百怪信息层

`world_view.gd`提供原生`WorldCamera`（0.65倍）与唯一世界矩形1840×710.769；原1280×720逻辑HUD继续放在独立CanvasLayer。这里取代v0.5的固定世界尺寸，角色/怪物的实际半径、速度、范围和伤害不变。`fantasy_environment.gd`按真实可视世界延伸地面；旧试验布局通过参考坐标转换。

`world_markers.gd`将必要名字/条形标注/减速状态按屏幕尺寸绘制，名字最多8条并避重叠，优先悬停、首领与稀有。普通满血敌人不铺血条；浮动伤害数字字号不随世界相机缩小。HUD原有响应式行为保留，含720p且UI110%时右下操作提示的紧凑隐藏规则。

相机/标注300检查通过，包含720p/1080p/2K变换往返及有界文字；原生720p/2K核对77个UI控件矩形/变换、40个字体节点，无变化。普通巡游体本体高度在720p从34px降到22px，2K从68px降到44px；怪物文字仍保留名义字号。

`density_visual_capture.gd`在真实主场景运行100只目录怪物的AI、施放飞弹和记录命中，高低特效共13份场景；优化调度后全部记录逐值一致，关键2K命中截图哈希也一致。原生鼠键另验证F7进入百怪、移动、1/2施法、96存活/4击杀、切换分裂试验和暂停退出。只有4秒聚堆QA夹具保护玩家，敌人值不改，正式模式不添加保护。

完整量测、CPU实测条件与极端同刻命中仍较慢的限制，见[视距与百怪](WIDE_VIEW_DENSITY.zh-CN.md)。这些检查不等同Windows硬件帧率或原生启动验收。


## v0.9：特殊珠宝与资料图形

`jewel_emblem.gd`复用装备图形绘制实际实例，寻枝有原创枝形纹样；`skill_emblem.gd`新增散束/凝束辅助符记。`tools/export_reference_art.gd`从现有运行绘制器导出36张离线PNG及清单，不依赖商业游戏图片。图鉴浏览器渲染受策略限制未验，但导出图片在原生绘制中生成并核对。

新增UI215项、原显示199项通过；装备图形扩展为20种轮廓/1860个边界内图元。原生720p/1080p/2K最大UI/字体下检查预览、远程点亮、依赖保护；实际鼠标完成远程退款1点、返回孔并取回珠宝。截图夹具使用额外天赋点方便观察，不能用它证明真实存档通过；存档与点数由独立规则/场景测试验证。

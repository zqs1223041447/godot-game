# 雾羽掠行体：少量高闪避目标

v0.71新增普通物种模板 `mist_skitter`，中文名“雾羽掠行体”。它沿用掠行体的 kind1、移动、体型与攻击频率，以更低血伤换取1600闪避；命中仍由玩家与怪物共用的 `AttackHitRules` 结算，没有专属命中公式。

## 出现边界

只在正式晴泉台地第二档（波次6）与第三档（波次10）参与编排。全部原据点编排、元素替换与所选巡逻处理完成后，每个据点只把第一个仍为普通白色 `skitter` 的根怪名额替换一次。没有合格名额就不出现，不补抽、不新增根怪。

每据点最多1只，三个据点合计最多3/36根怪；这是上限，不是每图保证3只。雷纹巡逻优先，可能令全图没有可替换名额。蓝色、金色怪物及其原机制保持，灰烬名额也保持。

正式第一档、旧庭、断垣、旧固定波次6的测试晴泉、首领和死亡后代均不进入这项替换。仅看波次6不足以满足出现条件，必须同时是正式晴泉第二档。

## 同波预算与构筑取舍

相对于同波普通掠行体：

- 闪避从320变为1600
- 最大生命与初始生命乘0.80，攻击基底乘0.85
- 移动速度、半径、攻击频率、攻击类型和已有奖励资格保持
- 没有额外经验、装备、宝石、药剂、材料或地图完成收益；没有新增随机抽样

第二档的实际普通模板生命由45变36，攻击基底由11.5变9.775。第三档仍从自己的同波基数乘上述倍率。已有地图普通词缀继续在后续原流程应用。

下表是现有 `AttackHitRules` 的独立命中值输入，不是假设装备、完整构筑排行、伤害倍率或实战DPS：

| 攻击命中值 | 原掠行体闪避320 | 雾羽闪避1600 |
| --- | --- | --- |
| 100 | 88% | 45% |
| 284 | 100% | 77% |
| 304 | 100% | 79% |
| 414 | 100% | 87% |
| 600 | 100% | 96% |

命中投资因此仍能改善攻击准入。[坚决技艺](RESOLUTE_TECHNIQUE.zh-CN.md)可将闪避准入变为100%，同时所有命中不能暴击；[精准技艺](PRECISE_TECHNIQUE.zh-CN.md)保持原先最大生命门槛与禁暴击代价，不自动绕过闪避。法术原本不进行攻击闪避。距离、墙体、出生保护、支付与后续护甲抗性等限制仍生效，100%闪避准入不等于无条件击中。

本批不给其他物种增加闪避，不开放其他天赋、装备词缀或流派系统，不改变存档schema45、物品池与奖励规则。视觉复用现有资源，没有新纹理或新的可玩发布包。

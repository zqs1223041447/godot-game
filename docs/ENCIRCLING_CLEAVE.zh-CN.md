# 环斩辅助

裂刃斩原有五个辅助均调节半径、伤害、魔力或频率。环斩提供第六个选项：用正面单次伤害换取周身覆盖，同一技能组仍最多五个辅助槽。

- 仅适配裂刃斩。原180°半圆改为360°圆周，主命中伤害总降25%，魔力消耗×1.25，冷却不变
- 默认半径95不变；广域、凝域与来源范围加成仍按原面积公式只计算一次。两倍角度覆盖不作为额外伤害倍率
- 未装其他辅助时，原280%基础/附加效用的物理攻击经独立0.75命中倍率结算；不修改原技能基础定义。原12魔力变15，原1.4秒冷却保留
- 每个现有目标最多结算一次，背后也必须通过距离、体积、真实墙体视线、出生保护与攻击闪避。圆的首尾角不会产生第二次命中
- 原暴击与偷取按该次施放及实际命中处理；无额外伤害事件、冲量、异常状态、重复施放或新队列。不适配普通攻击、法术、独立爆炸
- 与原五个辅助均兼容，仍拒绝重复同辅助及超出五槽。没有自动赠送；正式城镇售价4碎片，测试供应从当前目录生成
- schema51→52严格验证并备份原字节后仅开放新宝石身份，不变来源政策49、装备词汇51、冻结里程碑奖励序列或已有宝石链接

编译器只在装配时输出`encircling_cleave_profile`，其radius读取已经完成原面积计算的最终配方。实际执行和原弧线效果直接读取同一`recipe.half_angle`；没有另造显示范围或逐目标几何规则。原未装辅助的编译字段与行为保持。

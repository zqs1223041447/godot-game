# v0.5 随机装备：执行契约与研究边界

## 可执行范围

运行目录 `scripts/items/equipment_catalog.gd` 完全由原创名称、底材、分档、数值与权重组成。不会读取或导入 `data/reference/poe_affixes`。其 6 个底材、12 个词缀族、36 个原创档位，与研究资料的 1,200 条普通装备档位不是同一集合。

固定 9 件示例/机制装备保留原 ID 和效果。随机装备使用 `gear_000001` 形式的独立 ID；两件同底材装备是不同实例。实例只保存底材、稀有度、物品等级、词缀族/档位/掷值，不允许存档注入任意属性或脚本效果。

- 普通：0 词缀；魔法：1–2，至多 1 前缀与 1 后缀；稀有：4–6，至多 3 前缀与 3 后缀
- 族/排斥组不重复；底材部位必须支持该族；空池整次生成失败，不制造缺词缀的稀有物品
- 原创 T1 / T2 / T3 在物品等级 1 / 8 / 16 解锁，数字越大代表本项目的更高档，不能等同 PoE 的 T1 排名
- 选择的是合法族档组合，其权重明确配置；掷值为闭区间整数点/百分比刻度。较高等级仍可能生成低档
- 原始怪每 8 次有效击杀提供一次装备机会；稀有或 Boss 原始怪必定尝试发放稀有装备。同一次死亡最多发放一件；后代和试验场不给装备
- 物品等级为 `clamp(波次×2−1, 1, 30)`；这是原创进度节奏，不是 PoE 掉落公式
- 奖励直接进入背包。当前没有地面战利品、交易、制作、回收、筛选器或仓库。满仓提示无法领取新奖励，绝不覆盖旧物品

## 作用域和单位

- 生命、魔力、护盾：角色属性点数加值；本版没有局部护甲/护盾再汇总阶段
- 法术伤害：只匹配该伤害事件的 `spell` 标签；装备独立爆炸有 `secondary`，不会继承
- 火、冰、电：只匹配相应伤害分量；不修改不相关分量
- 攻击元素：必须同时具有 `attack` 标签且为火/冰/电分量；不作用于法术或独立爆炸
- 投射物：只匹配 `projectile` 事件；独立范围爆炸不继承
- 攻速、移速、魔力恢复：先把角色基础、装备、天赋和珠宝的每秒/点数加值相加，再乘 `1 + 各来源百分比提高之和`
- 攻速当前只影响普通射击的间隔；主动技能冷却保持独立，不提供施法速度或冷却回复
- 同一伤害分量适用的提高相加，再与已有独立更多相乘。施放时保存攻击快照，敌方抗性在实际命中时读取

## 背包与存档安全

每次随机装备/珠宝入库前，都以全部拥有物品做一次确定性排包，包括正在穿戴的装备和已镶嵌珠宝。这样卸装、替换、重置天赋必定能安全回包。格子不足则整次奖励失败，序号与存档不改变。当前 64 件生成装备上限是额外安全界限，格子容量通常会先达到。

v4 保留现有装备/快捷栏/天赋/珠宝字段，新增实例表与单调序号。v1/v2/v3 可迁移；第一次在原路径写入前保存原文 `.vN-backup.json`。备份冲突、原文被其他程序更改或备份写入失败均停止覆盖。错误的族/档位/数值、重复位置、错误计数器、越界布局或未知字段导致整份读档拒绝，不部分加载。

`get_item_definition(id)` 是 UI 和战斗的唯一物品解析入口。UI 不直接把实例 ID 用作固定目录索引；纯绘制不改变物品、装备或游戏存档。

# 探索地图路线与大小驻点

本批在原3600×2400探索地图中重新安排驻守位置，保留全部24/36普通根怪和1个首领。入场就建立全部实体；没有改回接近才出生、分波等待或追加普通怪。

四图均有六处驻点：旧庭是三对3+5怪的小群与较大群，另三图是三对4+8怪。使用三角、错位、扇形及弧形布置；较大的8怪群仍整组在场。玩家可自由选择道路或先去首领，不要求逐点解锁；路牌号码只是位置标识。

- 旧庭：开阔环线和中央连接路，便于主动把多个驻点引到一起
- 断垣：两堵错位长墙两端和内部通道分布，绕墙与视线仍有实际影响
- 晴泉：四泉池外环与中央十字通道，保留西侧偏霜纹、东侧偏掠行的原编排
- 银杏：中央花圃、两基台外侧与内廊分布，可借真实障碍绕行与断视线

浅色石道仅为静态平面导向，不新增墙体或移动限制。路线宽72单位，每段均通过实际几何的半径36完整扫掠与边界检查；所有驻点都连在入口可达的路径网中，并有闭环选择。出生位置按真实体型验证全图不重叠、无墙内成员，保持入口850单位净距。银杏西侧大驻点根据实际检查移至相对入口世界原点的(420,1080)，没有放宽入口保护或碰撞规则。

## 权威数据与兼容

`ExplorationMapLayout`新增`landmarks.outposts`及`route_segments`。原`camps`、`source_group`和每组ordinal只保留内部编排与旧身份兼容：每原8/12个成员顺序不变，拆成两个位置集合。每个驻点有稳定ID、原source_group、对应ordinals及实际root_ids；初始spawn_record新增outpost_id，原spawn_key构成不变。首领独立，不归入六驻点。

同profile／seed下，物种、稀有度、机制、战斗数值、实体ID、奖励资格、原始谱系及原子计划checkpoint保持；新位置与驻点显示身份明确是有意差异。走位和遭遇顺序会改变实际战斗，不宣称整场事件、自然击杀顺序或掉落抽样过程逐字等价。原费用0/4/8、基础完成奖4/8/12、词缀加奖、解锁和死亡后代限制保持。

Main的`outpost_states`只派生展示：驻守、战斗、清理；根怪全败但该谱系仍有活体或待出生后代时不得显示已清理。它不控制出生或战斗准入。根/后代死亡及既有唤醒更新点刷新，数据查询返回新字典；没有另造状态推进时钟。当前地图完成与HUD共同按已登记必需根怪/首领谱系判断：死亡须合法结算，活后代及队列清空；未知成员或未结算必需尸体阻塞。根怪完成进度独立于普通奖励资格，原经验、掉落、里程碑及药剂充能资格保持；详见[完成与奖励合同](EXPLORATION_MAPS.zh-CN.md#完成奖励与退出)。

旧小地图显式geometry/profile不修改；schema50、source49、equipment46保持，原存档无需迁移。未来赛季仍只接受空机制配置，不把冻结精英／精华或新分裂赛季视为本批功能。

# 蚀影飞弹＋牵引

蚀影飞弹现在可装配既有牵引辅助。成功的主投射命中结算后，将原45向外冲量替换为朝发射时角色脚下位置的190牵引初速。它提供站位取舍：角色仍在原处时，也可能把敌人拉近并增加贴身风险。

代价是魔力×1.20，占用一个辅助槽。基础魔力8→9.6；原伤害、混沌类型、弹数、速度620、穿透、射程、寿命和冷却保持。其他辅助仍按各自原规则影响这些数值；加入牵引本身不再次改变它们。独立爆炸继续结算原伤害，不附带牵引。

每枚选中投射物在发射时保留相同的角色脚下位置，不以偏移后的枪口、当前弹头或后来的角色位置作为牵引原点。发射后卸下辅助或移动角色，已有飞弹仍使用原点、伤害与冻结策略；后续新施放读取新装配。死亡目标、出生保护、墙体和原命中准入继续约束主命中。取消的投射物不会继续造成命中或牵引。

牵引沿用520/秒的冲量衰减、敌人移动、分离与身体墙碰撞。重复命中覆盖冲量，不相加；目标与原点重合时为零。没有持续吸附、瞬移或保证拉到原点，也不会给混沌命中新增冰缓、霜锁或其他异常。

复用正式商人的原牵引宝石，售价4校准碎片，购买入包后装入蚀影辅助槽。schema61保持，不赠送宝石或碎片，不修改其他技能兼容关系。

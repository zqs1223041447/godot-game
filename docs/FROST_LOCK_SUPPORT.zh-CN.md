# 霜锁辅助

只辅助冰霜脉冲，占用一个辅助槽，与寒意延长辅助互斥。主命中伤害乘0.75，魔力消耗乘1.20；原五枚投射物、两次穿透、3秒移动减缓和4秒冷却保持。其他合法辅助仍可组合。

## 冻结与免疫

只有冰霜脉冲的主投射物通过原出生与命中准入，造成正的实际冰伤护盾或生命损失，且目标仍存活，才施加冻结。零损失、致死命中、持续伤害、独立爆炸和其他技能附加冰伤都不触发。它不是按面板伤害或一次掷骰决定的几率异常。

| 目标稀有度 | 冻结时间 | 解冻后的免疫 |
| --- | ---: | ---: |
| 普通、魔法 | 0.60秒 | 1.50秒 |
| 稀有 | 0.35秒 | 1.50秒 |
| 首领 | 0.20秒 | 1.50秒 |

冻结不刷新、不叠加；多枚投射物和多个技能组共用同一怪物ID的冻结与免疫。精确到期即可恢复或重新准入。画面只标识正在冻结的敌人，免疫期间不继续显示冻结。

## 当帧边界与攻击接续

在当前命中结算边界elapsed附加，立即阻止tick末的新预警起手；下一敌方阶段暂停自主移动、接触攻击计时、预警蓄力、恢复及双响局部时钟。不追溯取消本tick已经结算的攻击。

原锁定圆心、已过蓄力与pulse序号保持，解冻后接续原攻击。跨解冻时刻的帧只推进解冻后的剩余delta；例如普通敌人在0秒被冻结，0.50至0.75秒这一帧中只推进后0.15秒。预警事件的相对时间补上前0.10秒冻结，避免将接续伤害错放到帧起点。

外力冲量、怪物分离、墙体碰撞、燃烧、感电、其他状态与护盾恢复继续。被冻结的敌人仍可能被推移；冻结不是外力免疫，也不暂停世界资源时钟。原3秒减速仍独立运行。

施放快照保留独立的compiled.freeze_profile和snapshot.freeze_policy；拆石、换装或退款不改变在途投射物。没有霜锁时不增加空冻结字段。状态最多保留100个既有怪物ID，免疫结束后清理；怪物死亡立即移除，玩家死亡、换图、返城或重启清空。

# PoE1 天赋词缀：来源、游戏适配与平衡回归

## 结论与边界

已采集固定版本的 PoE1 官方天赋源数据，并把可执行的数值机制接入本项目原创星图。保留 **181 节点、360 条连接、24 个核心天赋、12 个珠宝槽和全部原节点 ID**；没有复制 PoE 的树形布局、美术、人物职业、创意名称或长篇描述。

当前不是整套 PoE 天赋执行器。完整来源盘点与实际游戏投放分别记录：

- 来源：3,390 个树记录，额外去重 353 个精通效果
- 全量盘点：2,974 种独立词缀表达，含去重精通后的 5,357 次出现
- 可映射：14 类基础数值机制，覆盖 98 种表达、579 次出现
- 未支持：2,876 种表达、4,778 次出现，逐项带明确原因；不会作为空效果投放
- 对直接含数值的源节点：176 个全部数值行可表示，322 个仅部分行可表示，2,374 个无可映射行；另 518 个无直接 stats。这里的“可表示”不等于原节点的职业、精通选择和分配规则已实现
- 实际投放：重新校准原有 19 个机制包；新增 4 个原生伤害“提高”机制，共 23 个机制包。四种新增机制各替换 3 个小天赋，共 12 个实际节点

不宣称“照搬原数值即可保证平衡”。PoE 的基础数值、装备强度、点数经济、敌人防御、恢复规则与本游戏不同。本次交付的是可追溯参数、硬上限和可复现回归边界，后续仍须实战体验、不同装备组合与击杀时长检验。

## 2. 映射语义：来源值与游戏值分开

`data/passive_balance.json` 是运行时唯一数值权威；每个机制含原始来源值、来源模式、参考基础值、尺度系数和最终属性。加载器重算公式，拒绝来源公式与运行时数值不一致的配置，不会回退到旧硬编码。

### 固定参考值投影

本游戏既有生命、魔力、护盾、攻速、移速、回复等字段是加值，因此明确采用：

`本游戏加值 = PoE 原百分数 / 100 × 固定参考基础值 × 校准系数`

参考基础值为生命 120、魔力 100、护盾 60、伤害 18、攻击速度 1.7/秒、移动速度 240、魔力回复 9/秒、护盾恢复 13/秒。系数是本游戏设计参数，不是 PoE 官方强度评级。

例如来源 5% 生命提高，参考生命 120，最终系数 0.65，得到本游戏生命 **+3.9**。后续换装备不会重新把这个天赋当成最大生命乘区放大。来源中的魔力回复百分比也不会错误地直接当成每秒回复量；护盾恢复仍保留本游戏停伤 4 秒后开始恢复的规则。

初步路径模拟发现 12 点进攻分配达到 2.197 倍普攻输出，超出事先设置的 1.8 倍边界，因此继续降低加值投影尺度，并重测。最终数据的所有 source_refs 都已同步最终系数。

### 四种原生伤害提高

| 机制 ID | 每节点实际值 | 作用范围 |
| --- | ---: | --- |
| `poe_global_damage` | 3% | 所有伤害分量 |
| `poe_projectile_damage` | 5% | 带 projectile 标签的独立伤害包 |
| `poe_elemental_damage` | 5% | 火、冰、雷分量 |
| `poe_area_damage` | 5% | 带 area 标签的独立伤害包，不是范围半径 |

同一伤害分量上的“提高”相加。举例：通用 10% + 投射物 20% + 元素 30%，对火焰箭是 **1.60 倍**，不是 1.10 × 1.20 × 1.30。已有“更多”解析器仍是独立乘区，但本次天赋没有投放更多机制。龙卷爆炸是独立范围火焰包，不继承投射物伤害提高。

14 类可表示来源还包括生命/魔力/护盾的直接加值。它们作为可复用的数字原语登记；本次 23 个包主要使用 11 类百分比来源校准，不声称把每一个可表示源节点都搬进了树。

## 3. 节点投放和路径成本

每个节点仍花 1 点，只有已连通相邻节点可点。新机制替换原节点效果，不额外附赠，保留存档节点身份。

| 新机制 | 原创节点 ID | 从起点最少花费 |
| --- | --- | --- |
| 通用 | ember_3_1、ember_5_5、prism_4_0 | 3、5、4 |
| 投射物 | ember_4_4、ember_6_7、gale_5_4 | 4、6、5 |
| 元素 | ember_5_7、prism_3_3、tide_5_5 | 5、3、5 |
| 范围伤害 | ember_6_8、prism_5_4、aegis_6_3 | 6、5、6 |

最短成本由实际 360 条边的 BFS 验证，包含路费；没有把远端核心视为直接可选。起点/珠宝孔/核心节点不会被这份替换表覆盖。

## 4. 叠加与安全上限

所有已分配天赋的完整机制包先相加，再只对**天赋贡献**封顶。装备和珠宝随后独立叠加，不会被天赋上限误截断。单节点详情显示该节点原始贡献，构筑面板显示最终生效总属性；达到上限后继续同类投入可能不再增益，玩家可免费重置调整路线。

| 天赋贡献 | 上限 |
| --- | ---: |
| 伤害加值 | +14.4 |
| 生命 / 魔力 / 护盾 | +144 / +120 / +96 |
| 攻击速度 / 移动速度 | +0.85/秒 / +72 |
| 魔力回复 / 护盾恢复 | +6.75/秒 / +9.75/秒 |
| 通用 / 投射物 / 元素 / 范围伤害提高 | 24% / 36% / 36% / 36% |

目前每个新增机制只有 3 个位置，正常全树实际最多通用 9%、各专项 15%，比防御性配置上限更低。没有新增投射物数量、子箭数、返回次数、触发次数、更多乘区、冷却缩减、暴击或异常效果；因此不会把子箭、返回和自然结束爆炸的数量乘起来。载体生命周期和命中账本沿用既有底层测试。

## 5. 同点数构筑回归

`tests/passive_balance_cases.json` 固定 240 条合法分配序列：12/24/48/96/180 点五档，每档六种目标权重（进攻、防御、混合、魔力、速度、元素）× 六个初始分区，再加 12 条固定随机种子的连通路线。每一步都通过实际 `allocate_passive`；所有样本都包含路费和可能经过的空珠宝孔。

对照组与测试组都为**空装备、无镶嵌珠宝**，因此默认武器伤害不会冒充天赋收益。数值由实际 `BuildState`、施放快照和 `DamageResolver` 复算，独立 Python 预算仅用作交叉校验。

| 花费点数 | 普攻 DPS 最大倍率 | 元素投射物单次最大倍率 | 生命+护盾最大倍率 |
| ---: | ---: | ---: | ---: |
| 12 | 1.7650 | 1.6662 | 1.4572 |
| 24 | 2.1739 | 2.0790 | 1.7128 |
| 48 | 2.9603 | 2.3580 | 2.2545 |
| 96 | 3.2766 | 2.4120 | 2.3333 |
| 180 | 3.2766 | 2.5020 | 2.3333 |

各列最大值可能来自不同构筑，不能拼成一套“最佳构筑”。回归边界分别为普攻 1.8/2.6/3.1/3.4/3.4 倍、元素投射物 1.7/2.1/2.5/2.6/2.6 倍，生命+护盾 1.65/2.1/2.35/2.35/2.35 倍。超界会让测试失败，不能仅重写快照掩盖超界。

普攻 DPS 假设持续命中；主动伤害指标是同技能单次伤害比例，未把攻速错误地当成技能冷却缩减。生命+护盾仅是当前无额外减伤时的容量代理；不是完整生存评分。此次覆盖不包含移动躲避、怪物密度、击杀时间分布、全部装备/珠宝组合或未来机制。240 条样本不是所有等点数路径的穷举；全树正向属性的上限也不等同于绝对游戏平衡证明。

## 6. 怪物共用与排除

玩家和怪物通过同一个 `MechanicRegistry` 取完整包；没有第二份怪物专属效果数值。怪物角色系数当前为 1.0；若调整，必须均匀乘整包，保留相同机制语义。

13 个既有纯加值包可被怪物使用。涉及魔力/魔力回复和四类伤害标签的机制在当前怪物执行器不支持，必须**整包拒绝**，不能丢掉一半字段后假装有效。普通无词缀、魔法最多 1 包、稀有/首领最多 2 包。

额外穷举 3 个物种 × 13 × 13 个双包组合，共 507 个怪物构筑（包括重复包压力案例），与相同物种、波次 1、相同稀有度的无包怪物对照：

- 伤害最高 1.2925 倍
- 生命+护盾最高 1.41184 倍
- 移动速度最高 1.281081 倍
- 攻击速度最高 1.11271 倍

四项都低于单独设定的 1.5 倍双包预算。稀有度本身的生命/伤害倍率与波次成长不混进这次词缀边际收益比较；整场难度仍由怪物集成测试与实战调节负责。

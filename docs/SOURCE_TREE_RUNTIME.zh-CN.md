# 源树接线与执行边界

本阶段以 3.29.1 的锁定原始数据为依据：3390 条记录、标准图 2387 个有位置的节点与 2697 条内部边。42 个位置代理和30个涂油专属节点仍保留显示，但不能直接分配。升华与扩展分区不连接到主树，不凭数据导入授予免费点数。原始图像没有进入运行资源。

这不是全树效果已完成。节点中任何一条效果尚无消费者时，整个节点不可分配；精通按所选效果逐项检查。原文、数值、连接和不可分配原因可以查看。锁定会阻断其后路径，界面以灰色斜线显示，不能把部分效果偷偷当完整节点出售。

## 已接入的基础消费者

42 种完整锚定格式，包括原17种容量/伤害/速度词句，三属性、物理/混沌/近战物理/攻击物理作用域、命中/闪避、护甲、三元素抗性、生命回复及明确的双属性/全部属性组合。未知条件、武器限定、召唤物、持续伤害专用词句仍拒绝。百分比按原数值除以100；没有旧181节点投影的缩放或加值上限。

力量、敏捷、智慧先按源职业基础值加全部合法加值，再取整。力量每2点取整增加1生命，每5点取整增加1%近战物理伤害；敏捷每点增加2命中值，每5点取整增加1%闪避；智慧每2点取整增加1魔力，每10点取整增加1%护盾。3.28官方已将智慧护盾系数改为每10点，不能沿用旧每5点版本。[官方3.28公告](https://www.pathofexile.com/forum/view-thread/3913392/filter-account-type/staff)、[PoB属性消费者源码](https://github.com/PathOfBuildingCommunity/PathOfBuilding/blob/dev/src/Modules/CalcPerform.lua)（2026-10-03核对）

现有游戏的生命/魔力/护盾、装备基础伤害仍是本项目基础值，源职业属性在此之上按明确阶段派生。未把本项目角色冒称原版PoE角色。攻击命中基础值100、闪避基础值15、怪物缺省命中100是当前原型平衡值，没有导入原游戏全部等级表。新模型自然敏捷型怪物的基础闪避为320，其余为0；默认Scion命中值140对此为96%命中率，额外10敏捷达到100%，让命中投资有真实自然遭遇消费者。根怪与死亡子代都读取同一档案，不加奖励、不改体型。

命中概率采用 `round(125 × accuracy / (accuracy + (evasion / 5)^0.9))%`，限制5%至100%；零闪避确定命中。法术不做此判定。玩家和怪物使用同一判定函数；每个防守者使用独立熵累加器，本项目选择确定初值50，不消耗掉落/视觉随机流。攻击施放快照保存当时命中值，命中时读取目标实时闪避。落空箭不消耗贯穿、不触发命中减速，单阶段同一碰撞体不会重复重掷。[PoB命中公式源码](https://github.com/PathOfBuildingCommunity/PathOfBuilding/blob/dev/src/Modules/CalcDefence.lua)

三元素抗性对各自分量生效，有效值当前为0%至75%；护甲对单次物理命中按 `armour / (armour + 5 × physical_hit)` 减伤，最高90%。更大物理命中的减伤比例会下降，不能缓存成固定百分比。先命中许可，再分量防御，再护盾，最后生命。生命回复在真实模拟tick中按秒执行。伤害预览说明成功命中且敌防前的数值，没有把它伪装为总DPS。暴击、格挡、压制、异常、穿透、混沌绕盾等仍未实现。

## 点数、精通与珠宝

普通成长预算为 `min(level + 4, 123)`。自己的起点免费，每个其他节点或精通消耗1点。剩余+已用必须精确等于预算。旧点数返还及超过123的差额在迁移账保留，不静默删除。Scion仍是旧档迁移默认；没有分配其他节点时可以原子切换到七个源起点之一，不能带着旧起点分支免费换职业。

普通连通不经过精通或位置代理。精通必须在同组普通连通的显著节点激活后选择，重复精通效果ID拒绝。镶嵌孔必须普通连通，寻枝晶玉只允许其280源坐标单位范围内的小型/显著节点断连分配，不能从远程节点向外扩路。280仍是本游戏初版规则，未改成原游戏某颗珠宝。移动珠宝、退款、换孔都验证最终完整候选，不允许形成循环授权或遗留失去支持的节点。

当前实际源路径定向验证：默认Scion六个首步均有完整执行；沿已执行节点可以到达555个节点（含起点，未等同可同时花555点），并包含可执行精通路径。其他节点继续保留原文并锁定。完整覆盖表将在图鉴中同步生成，不能以555推断全部3390机制完成。

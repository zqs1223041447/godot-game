# 奥能新星＋寒意延长

奥能新星现在可以装配既有寒意延长辅助：原0.6秒普通减速延长至0.9秒，主命中伤害乘0.90，魔力乘1.10。原155基础半径、190击退初速、冷却和闪电／法术／范围／命中身份保持；其他辅助仍各自提供原取舍。

这项辅助延长已有的减速。敌人的移动速度仍使用原0.36倍率；再次施加取原剩余时长与新时长的较大值，不相加，也不叠加减速强度。沿用原世界delta更新，单帧到期后按原规则恢复移动，不引入独立计时器。

与符印伏击同用时，在放置时冻结0.9秒，放置当下不伤害或减速；拆下辅助、移动角色后，已有符印仍在原位置触发并应用冻结时长。原出生保护、墙体、触发半径、共享容量、收费与取消规则继续有效。

新星仍是普通减速，不是冰霜异常；源树“冰霜异常时长提高”不延长它。冰霜脉冲仍沿原顺序计算：3秒×寒意延长1.50＝4.5秒，再由原20%冰霜异常时长来源得到5.4秒。没有向新星开放霜锁或新增伤害标签。

使用原寒意延长宝石，占一个原辅助槽，schema61不变。已经拥有时直接从背包或原技能组转移即可，无需重复购买；没有新增赠送或迁移奖励。未选该辅助的新星、既有冰霜和其他技能保持旧结果。

[F8技能卡](reference/index.html#skills-nova)和[辅助卡](reference/index.html#supports-lingering_chill)同步展示真实编译值。基础角色示例为70.2→63.18防御前伤害、24→26.4魔力、0.6→0.9秒；不是每秒伤害或自然战斗收益。[有限验证记录](qa/nova-lingering/README.md)包含实际命中、移动、伏击冻结、复用拥有权和保存重载。

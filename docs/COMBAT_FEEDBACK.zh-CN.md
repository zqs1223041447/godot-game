# 实际战斗反馈

反馈使用已经接受的实际损伤：护盾扣减加生命扣减，排除过量伤害、免疫、闪避和零损伤。主命中及独立爆炸各取自身最终暴击结果；普通、暴击、燃烧分别显示，燃烧不继承暴击标签、也不把采样数叫命中次数。

同一轮、同一目标、同一类别首次正损伤开启固定0.20秒窗口；到期显示累计数值，后续窗口不延长旧窗口。每个键最多一条可见数值，新结果替换旧结果，显示0.75秒。死亡立即完成末击；暂停冻结展示时间，地图完成后仍到期，重开、返城与切档清空。不同技能可在同类合计，因此不标单一技能名。

最多303个待聚合桶与48条可见数值。容量超限只提前完成最早桶或淘汰最旧显示，不更改真实损伤，不把不同目标合为一条。每次真正命中的旧位置随机抽样和原粒子抽样保持在原时序；新队列容量、合并、关闭数字均不会跳过它们，燃烧反馈不新增随机。

普通命中使用浅羊皮色，暴击金色感叹号，燃烧低饱和铜色“燃”；玩家受伤红色负号，三类分行。微小正数不显示成零。复用伤害数字开关、字号与相机缩放，无新常驻面板。

本批仅改变展示：schema28、构筑、技能配方、怪物密度、伤害、冷却、点燃、偷取、奖励与保存规则保持。[验证与限制](qa/V046_FEEDBACK_VALIDATION.zh-CN.md)。这不是DPS面板，也不代表Windows密集战斗性能已达某个帧率。

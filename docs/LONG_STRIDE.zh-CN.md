# 长跃辅助

长跃辅助仅适配闪光冲刺，用本次冲刺的新增保护换取更长的请求距离。

- 请求距离由175提高到280；这不是保证到达的距离。实际移动仍经玩家体积、竞技场边界与真实墙体碰撞处理，可被截断或沿墙滑动，不能穿墙；镜头和冲刺表现跟随实际到达点
- 本次冲刺新增保护由0.6秒改为0。只跳过本次冲刺的保护授予，绝不清除或缩短已有保护，也不回退已有保护的剩余时间
- 魔力消耗×1.20，未装其他辅助时12→14.4；长跃自身不改变原3秒冷却。效率、快速施法与原魔力、冷却修正仍照常计算
- 兼容效率、快速施法，占用原五个辅助槽中的1槽；仍拒绝重复同辅助和超槽。不适配守护结界或任何伤害技能，也不产生伤害包、投射物、暴击、偷取或异常状态事件
- 正式城镇售价4校准碎片，测试供应从当前目录动态生成。没有自动赠送；普通里程碑奖励池和序号保持
- schema52→53严格验证旧存档并备份原字节后，仅开放长跃宝石身份；源政策49、装备词汇51、已有物品、链接、点数、材料及普通奖励序列保留

编译器只在选中长跃时输出 `long_stride_profile`。实际Main读取其中的请求距离并走原移动几何；移除长跃恢复普通冲刺的原编译结果。无效配置在移动、资源、冷却、随机序列、表现及存档变化前拒绝。

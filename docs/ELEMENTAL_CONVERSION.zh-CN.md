# 三元素转换与命中穿透

v0.78 在既有火焰精通 65020 的 40% 物理转火之外，接通冰霜精通 4116 的 40% 物理转冰霜、闪电精通 53046 的 40% 物理转闪电。完整接通前置显著天赋 8833 冰霜之心、56716 雷霆之心：各保留对应元素伤害提高 30%，并实现对应命中穿透 6%。存档 schema 与当前源执行政策升级为 48；装备词汇仍为 46。

名称对照：8833 的原名为 Heart of Ice，当前天赋界面显示“之心的冰”；56716 的原名为 Heart of Thunder，当前显示“之心的雷霆”。本说明使用较自然的“冰霜之心／雷霆之心”称呼，定位时可直接搜索节点编号。本批没有改写既有中文名字典。

这是本游戏明确实现的有限转换规则，不声称完整复刻外部游戏。原始英文、节点身份、拓扑、中文映射文件与素材保持；没有新宝石、词缀或掉落。

## 同一角色可达，精通按效果唯一

共同路线使用 23 级女巫，预算为 27 点。25 个普通节点含免费起点，花 24 点；三种精通各花 1 点，共花 27 点。它是一条合法可行路线，不是最短路线结论。

- 共同前缀：54447 → 57226 → 21678 → 32210 → 8948 → 38176 → 49651 → 5296 → 19501
- 冰霜分支：19501 → 5972 → 36412 → 22090 → 40609 → 8833；同组选 60170 / 4116
- 火焰分支：19501 → 4367 → 44184 → 61804 → 13559 → 31462 → 11924；同组选 34927 / 65020
- 闪电分支：4367 → 32431 → 36121 → 57362 → 55647 → 56716；同组选 58816 / 53046

精通不作为通路。多个同元素入口共享同一效果 ID，不能重复取得；退款后才能更换入口。两种新精通的其他入口仍需要完整可执行且普通连通的同组显著天赋，源数据存在不等于可分配。

F8 对照使用实际 Main 验证过的同源构筑。未选三精通的对照仍保留 8833、56716 的 30% 增伤与 6% 穿透，剩 3 点；不能把它称为旧版本或完全没有新词条的构筑。所有示例是成功、不暴击的单次命中，不是实战 DPS 或最佳配装。

## 先组装，再统一分配

先组装技能固有物理、按附加效用缩放的外部物理点伤，以及按实际命中系数加入的局部武器物理。统一转换只处理这份合计物理 P；原生元素独立保留。

- 一种请求 40%：该元素得到 0.4P，物理留下 0.6P
- 两种各请求 40%：两元素各得 0.4P，物理留下 0.2P
- 三种各请求 40%，总请求 120%：按总请求归一，各得约三分之一 P；残余物理显式为 0

请求总和不超过 100% 时保持各请求比例；超过时按总额归一。没有按元素先后顺序抢占，也没有超过原物理基底的额外伤害。龙卷原有固有基伤 60% 物理 / 40% 火焰是更早的技能组装，不是第二次转换。

转换部分保留 physical 与最终元素两种来源；原生部分只有自身来源。每条 modifier 数组记录至多匹配一次，同 id 的不同记录仍分别计入。increased 在每一部分内相加，独立 MORE 逐条相乘，之后按最终类型合并为一条 detail，再进入防御。

物理专注对三种转换部分均同时匹配 1.20 与 0.80 两条独立条款，结果为 ×0.96。火焰专注对转火部分为 ×0.96，对转冰霜、转闪电部分只有 ×0.80。不能按 id 去重，也不能只按最终类型选择有利条款。原生元素按自身来源匹配。

## 穿透只影响当前命中的最终元素

8833、56716 分别提供 6% 冰霜、闪电命中穿透。按目标已有规则取得有效抗性后，先沿既有范围限制为 −100%～90%，再减对应穿透，最后只守住 −100% 下限，不再次按上限钳制：

r_used = max(−1, clamp(existing_target_resistance, −1, 0.9) − 0.06)

因此零抗性变为 −6%，75% 变为 69%，90% 变为 84%，原 −100% 保持 −100%。只读取最终伤害类型；历史物理来源不让火焰获得冰霜或闪电穿透。不修改目标抗性属性，不创建曝露，不影响其他来源之后的命中。

DamageResolver 的默认空目标表示零抗性目标。启用穿透后，预览总量已经包含零抗性被穿到负值的收益；防御前 before_defense 字段仍不含穿透。F8 分开列“防御前分量”和“零抗性、零护甲目标，含穿透”，避免混称。

## 偷取、燃烧与适配边界

全攻击生命/魔力偷取仍依据敌人实际损失的护盾加生命，超杀不增加偷取。物理攻击偷取只依据防御后的残余物理在实际损失中的份额；三种 40% 请求归一后没有残余物理，物理限定偷取基数为 0。转换部分的历史物理来源不会再次计入物理偷取。

已有点燃与余烬扩散取最终防御前火焰合计一次，随后沿原有火焰持续伤害加成、加速燃烧和燃烧准入处理。持续伤害不转换，也不读取命中穿透；现有独立纯火爆炸保持。没有新增普攻、裂刃等技能的点燃资格。

转换不扩展感电、霜锁或原生元素专注辅助的技能适配；有某元素分量不等于可装任何同元素辅助。没有多段转换、元素转另一元素、额外获得伤害、Avatar of Fire 或新异常机制。

## 冻结包与迁移

原始属性字段为 physical_to_fire_conversion、physical_to_cold_conversion、physical_to_lightning_conversion，分别只接受有限数值0或0.4；非法比例、非数值、非有限数、重复转换、错误来源/目标与伪造拆分均拒绝。

无转换与仅旧火转换继续保持旧返回结构和算式。新多元素配置使用 version 2 转换记录，保存 requested、effective、remaining_base 和各元素 converted_base；原始 base 与 assembly 仍是转换前证据。每个最终类型只输出一条 detail，parts 保留各部分来源和修饰器下标。

穿透在施放 snapshot.hit_penetration 与实际适用的 packet.penetration 冻结，cast.penetration_profile 只列包中实际存在的最终元素。detail 的 effective_resistance 是目标原有效抗性，penetration 是本次穿透，resistance 是最后实际使用的抗性。已在途母箭、子箭、返回、符印与已建立燃烧继续读取原快照；退款、换装、换辅助只影响后续新施放，不反复转换。

schema47 → 48 先严格验证旧词汇并保留原字节备份，再通过版本升级接入新词汇；不赠点、不赠物、不重掷、不改 UID。旧 schema 注入本批新节点或新精通应拒绝，不得借升级绕过旧校验。

当前五个怪物源绑定仍只有原移动、伤害、生命、护盾、充能语义，没有新增转换或穿透。源政策 45 → 48 会刷新新生怪物定义及溯源 metadata，数值不变；已存在 actor 保留出生快照，不追溯改写。不能宣称新生 actor 的所有字节与旧版本完全相同。

# 余烬扩散辅助：本游戏初版合同

本游戏初版预算已完成代码定向验证；导出与发布状态由本版交接清单单独确认。

- 稳定ID `ember_proliferation`，与点燃辅助互斥；适配陨星、龙卷，占现有一个辅助孔
- 主命中×0.75、魔力消耗×1.30；火焰主命中附燃3秒，每秒取最终防御前火分量20%。独立爆炸不附燃
- 由此直接附燃、仍有剩余燃烧的敌人死亡时，向中心距离120内最多8个活目标传播；距离优先、同距按ID，遵守实体墙LOS、出生保护
- 传播保留原始DPS与绝对到期时刻，只走一跳。传播燃烧不继续传播、不重套命中/投射物/暴击/偷取，不生成即时伤害
- 仍沿用强覆盖弱、同强刷新规则；刷新到传入的原到期时刻，不重新给予3秒。普通点燃覆盖后也不会暗中保留扩散资格
- 瞬杀未形成燃烧、到期、取消、重复死亡不传播。只有一次权威死亡触发；后代原有零奖励规则不变
- schema29只扩宝石词汇，合法28原字节备份后迁移，不赠物、不改UID/奖励序列；正式商人4碎片，测试免费供应沿真实动态目录
- 使用实际结算事件时刻保留余时；同tick死亡按时间再ID处理，旧无新辅助路径保留原执行路径

范围仅此机制、真实取得/存档/组合与定向验证；不新增经济或地图，不开放尚未实现的源树持续伤害词条。

新余烬启用时按最早真实致死时刻推进全体怪物燃烧；每个时刻先结算损伤/死亡，再向存活目标传播。普通点燃在无新辅助时保留旧执行路径。长时钟不足一个浮点单位的正时间推进至下一可表示时刻，避免零宽循环；绝对到期时刻不延长。

# 天赋资源上限预览

T 天赋界面选中可分配或可退还节点后，详情会显示此次操作造成的生命、魔力、护盾上限变化。只列实际变化的项目，例如 `生命 142.0 → 149.1（+7.1）`；数值最多显示两位小数。其他伤害、防御、恢复效果仍看原节点说明，此区域不代表全部构筑收益或总战力。

复用 `passive_action_preview()` 已有分配／退款计划，先准备并验证候选，再用实际构筑的 `_stats_for()` 分别编译当前和候选统计。装备、已插珠宝、属性派生、百分比及特殊天赋覆盖均走原编译器；不按词条文字另算一套。例如混沌异种将生命上限最终覆盖为 1，此时生命百分比变化不会产生虚假的生命提升。

非法、未接通、未实现或不可退还操作继续显示原权威原因，不提供无法执行的资源预测。预览不提交候选、不更新当前统计缓存、不保存、不消耗点数或随机数。实际点击仍由原事务独立验证和保存；预览不保证磁盘写入一定成功。

没有新增存档字段或改变 schema59。查询返回的 action 增加 `resource_changes` 字典，仅用于展示，不写入角色数据。

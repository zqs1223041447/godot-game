# 探索地图总览

正式探索地图中按 **Tab** 打开或收起总览，**Esc** 先收起总览。总览显示玩家当前位置与朝向、入口、六个驻点、首领原址和实际障碍。战斗与移动继续；可以照常施法。打开行囊、技能等菜单、死亡、离图或重新开图会关闭旧总览。

清理到 1–5 个活敌人时，粉色圆环标出当前最近余敌的位置，与驻点原址标记分开。复用原有余敌提示的目标选择、死亡过滤及后代归属，不新增全图敌人雷达；只剩待生成后代时清除圆环并提示等待。仍需自行绕开实际障碍。

这是当前整张地图的导航视图，没有迷雾、点击移动或传送。黄色表示未清驻点；橙色表示已唤醒怪物或待生成后代；绿色双圈表示驻点已完全清理。驻点与首领标记保留原址，不声称敌人当前仍站在那里。首领已败也不等于整张地图已清空。原有少量余敌方向提示继续提供清理阶段的实时目标方位。

绘制只读取现有 `world_geometry()`、`world_context()`、玩家位置与朝向。四张普通地图使用原碰撞矩形；遗迹庭园直接使用已准备好的四个原生碰撞多边形（99 个顶点），不重新提取资源，不用外接矩形替代。驻点状态来自原 `_outpost_states()`，包括待生成后代；总览没有自己的通关判定。

开启时复制几何，打开期间每帧更新玩家，至多每 0.2 秒主动刷新一次驻点状态；已有世界状态通知也可刷新。视图关闭时不轮询世界状态。没有新增保存字段、物品、UID、收费路径或随机调用，schema 保持 59。

验证见 [专项记录](qa/exploration-map-overview/README.md)。

余敌标记与原 HUD 共享同一次查询，主动轮询仍按 0.2 秒间隔；切换地图模式或运行批次会立即更新快照，世界通知仍可更新总览，因此不是所有更新的硬性 5Hz 上限。[余敌及正常处理短测](qa/overview-cleanup-target/README.md)另有记录。

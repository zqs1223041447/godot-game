# 龙卷射击＋疾速投射辅助

疾速投射辅助现在可以装入龙卷射击技能组。它沿用现有宝石身份、图标和正式商人价格：在城镇宝石商人花4枚校准碎片购买，进入背包后装入龙卷的一个辅助槽。旧档不会免费获得新宝石。

| 参数 | 无辅助 | 疾速投射 |
|---|---:|---:|
| 母箭速度 | 420 | 567 |
| 子箭速度 | 260 | 351 |
| 魔力消耗 | 18 | 19.8 |
| 每枚母箭的子箭数 | 3 | 3 |
| 母箭／子箭射程 | 150／150 | 150／150 |
| 母箭／子箭寿命上限 | 0.9／1.7秒 | 0.9／1.7秒 |

表中不含其他构筑修正。母箭和子箭速度均乘1.35，魔力乘1.10；现有投射速度提高随后按原规则相乘。伤害分量、命中倍率、冷却、穿透、数量与独立爆炸参数不变。加速会改变分裂和返回发生的时间，并不增加距离或刷新寿命，也不表示持续输出提高35%。返回与爆炸仍须由原装备赋予。

施放时冻结最终母箭、子箭配方。箭已飞出后卸下辅助，既有母箭以及它随后生成的子箭仍使用原速度；下一次施放读取新构筑。缓速强击、寒意延长及贯穿辅助仍不适配龙卷。

这是有意扩展原兼容白名单，覆盖历史说明中的“疾速投射不适配龙卷”；没有改其他辅助规则、存档schema、模型或渲染。游戏内说明和离线图鉴同步来自当前目录与编译结果。

# 更快燃烧：相同总量，更短窗口

现有“伤害型异常状态结算加快”支路有三个完整节点：11364与43684各5%，Dirty Techniques59766为15%。同类相加，全支路共25%。本游戏当前只实现燃烧消费者，不因此宣称已有流血或中毒；感电不属于持续扣伤，不受影响。

倍率在初始施放时冻结。先按原有火伤、命中、暴击和火焰持续伤害加成得到燃烧DPS，再乘1+加快比例；时长除以相同因子。例如每秒30、持续3秒变成每秒37.5、持续2.4秒。总量理论同为90，但刷新更频繁、击杀可能更早、余烬的可传播窗口缩短。这是本项目当前规则，不表示所有源游戏异常机制都已接通。

点燃与余烬扩散共同支持。传播继承已经计算的DPS和已经压缩的原绝对截止，不再次加快，不重开完整时长。正在飞行的母子箭和已经附着的燃烧不会因后续退点变慢或延长；下一次施放才读取新构筑。直接命中、魔耗和敌人燃烧仍沿原规则。

单目标继续以实际DPS比较强弱；更高DPS的短状态可以替换更低DPS的长状态，即使其总量更低。已被替换的弱状态不会在强状态结束后恢复。相同DPS仍按原规则刷新。技能卡的DPS、总量和时长都是最终结果，新增说明行不是需要再次乘算的增伤。

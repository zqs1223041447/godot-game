# 16 辅助批次：新星、陨星与连锁真实场景验收

入口：tests/support_area_chain_batch_integration_test.gd。本专项实例化 scenes/main.tscn，通过实际构筑事务设置技能和辅助，再调用公开的 main.cast_skill(0)。没有替换施法、寻敌、伤害结算或视觉提示实现。

## 完整组合矩阵

每个技能验证空辅助、五个单辅助、十个不同辅助两两组合，共 **16 × 3 = 48 行**。注册表的适配列表必须与下表完全一致，防止少测新增组合。

| 技能 | 五个合法辅助 | 行数 |
| --- | --- | ---: |
| 新星 nova | 广域、凝聚、闪电专注、节能、快速施法 | 16 |
| 陨星 meteor | 广域、凝聚、火焰专注、节能、快速施法 | 16 |
| 连锁 chain | 连锁延展、远链、闪电专注、节能、快速施法 | 16 |

每行均检查：

- 魔力低于精确消耗 0.001 时，施法原子拒绝；精确魔力可以施法且扣到零；资源倍率乘积和冷却不做显示舍入
- 冷却中的第二次施法不再扣费、不新增伤害或视觉提示；区域与连锁技能不生成投射物，total_shots 保持零
- 实际 damage_trace 的五种伤害分量、抗性前分量、被抵消分量、修饰符明细、组装来源、总量，与施法前保留的编译包和命中时目标防御逐项相等
- 抗性先于护盾和生命结算；实际生命与护盾变化、减速时长符合既有语义
- 施法后通过实际装备事务更换为疾风短刃并改变辅助，新编译读取新装备；已保留的旧施法包、已发出的视觉提示和已结算命中记录保持不变

另有每个组合的空场景施法，共 48 个无目标场景：仍正确扣费和开始冷却；新星、陨星保留原有脉冲，陨星使用前方 220 的原有落点；连锁不生成虚假命中或闪电弧。

## 区域几何

| 配置 | 面积倍率 | 新星半径 | 陨星半径 |
| --- | ---: | ---: | ---: |
| 无区域辅助 | 1 | 155 | 110 |
| 广域 | 1.44 | 186 | 132 |
| 凝聚 | 0.64 | 124 | 88 |
| 广域 + 凝聚 | 0.9216 | 148.8 | 105.6 |

每行都实际命中中心目标和“半径 + 真实怪物体型半径 − 0.01”位置的目标，跳过“半径 + 体型 + 0.01”、出生保护期目标和尸体。整数半径还检查精确边界相等时包含目标。非整数的 148.8 / 105.6 使用内外 epsilon，不把 float32 Vector2 中不能精确表示的值误当作数学上的精确边界。视觉脉冲半径必须等于未舍入编译半径。

## 连锁路径与预算

- 密集夹具为间隔 180 的八目标折线路径。基础及未安装延展的组合命中五个；延展组合命中七个；第八个始终不命中。bounce_count 表示含首目标的总数
- 同一个活目标还会重复加入世界数组，实际寻敌仍按身份去重。更近的尸体与出生保护目标均跳过
- 每一命中的基础系数及外加效用都保持 2.2 − 索引 × 0.2，新增第六、七个目标对应 1.2 / 1.0。实际闪电弧的起点、终点、目标身份与命中顺序完全一致，整链共享施法身份
- 稀疏夹具为间隔 250 的八目标折线路径。无辅助和仅延展都只命中一个；仅远链命中五个；延展 + 远链命中七个不同目标，证明增加目标数与增加可达距离分别生效
- 首目标距离依旧为 600；远链只将后续距离从 220 改为 286。基础、仅远链、延展 + 远链均检查距离内 0.01、等于边界、边界外 0.01。沿用现有 _nearest_enemy 的严格小于比较，恰好等于 600 / 220 / 286 不在寻敌范围内

连续施法专项对三个技能分别施放旧构筑、更换实际装备及辅助、把目标有效火抗改为 50%，再施放新构筑，确认新命中读取新构筑与当前防御。随后用旧冻结包直接进入既有 _apply_damage_packet 命中消费者，单独证明当前目标防御不会冻结进旧施法包。

## 夹具与自然内容的区分

这里使用真实目录的巡游体与灰烬守卫，通过正式场景生成函数创建；保留真实体型及灰烬守卫原生 25% 火抗。真实构筑的默认武器和后续装备变化决定基础伤害。

为隔离结算和几何，测试暂停场景与 HUD 帧处理，关闭自动攻击和定时刷怪，固定玩家/怪物位置，将生命设为 10,000、护盾设为 9，并显式设置出生保护与尸体状态。五分量外加伤害 physical=2, fire=3, cold=5, lightning=7, chaos=1 来自仅存在于测试的 FixtureState；这是类型筛选探针，不宣称该装备组合自然可获得。连续施法中的 50% 火抗也是明确的防御变化夹具。以上均不作为自然掉落、自然刷怪、性能、DPS 或长时生存证据。

实际工厂生成第2波金色巡游体和第10波金色重壳体，各有无词缀、旧/新储盾、旧/新复苏、旧/新双辉壁七组。每组检查平原护盾、基础/实际回复、4秒延迟、护幕新增量、强健＋护幕、受损护盾缺失量保持。新身份只对M乘冻结容量倍率，S不重乘；无新身份保持原地图加法。完整数值见 [合同](../../SOURCE_MONSTER_SHIELD_RECHARGE.zh-CN.md)。

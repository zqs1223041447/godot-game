# 技能与行囊：主开发直接重做的界面

本轮遵循用户 2026-10-03 的反馈：左右各约三分之一，技能与属性共用左侧、行囊独占右侧；装备保留上图下字的九槽结构；五个辅助孔突出图像而不是大段说明。

## 直接修改

- 增加仅用于双栏的统一配色/边框组件 `DockVisualStyle`，不修改战斗或存档规则
- 紧凑深棕标题带、象牙色高对比标题；技能行用浅色分组底面，避免每一行都是同样的厚金框
- 主动图标比辅助孔稍大，辅助孔采用有内外明暗的圆形凹槽；保留真实父槽的鼠标与拖放所有权
- 装备保留原先的绘制材质与上下图字关系，行囊操作按钮统一较小字号
- 背包物品不再重复显示底部短名或大色条；真实图像、稀有度边框与悬停卡承担识别
- 不增加主辅孔、背包容量或隐藏余额，不改变 UID、分页、冷却或掉落

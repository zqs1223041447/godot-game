## One bounded export

[`tools/resistance_targeted_reforge_reference.gd`](../../../tools/resistance_targeted_reforge_reference.gd) reads the completed model report, validates its 28 source/output equipment instances with the current Catalog, derives their display definitions, and exports only the four target metadata/eligibility records. It does not instantiate the model, open a scene, execute a transaction or write a game save. It checks the full exporter's four new example helpers are legal and quotable, and compares all ten old helper outputs to their original expressions using exact `var_to_bytes` equality. It never calls the full `crafting_examples()` or full exporter.

[`run-export.py`](run-export.py) freezes 339 source/evidence inputs and uses isolated temporary Godot data directories. The sole export passed in about 4.45 seconds with exit 0 and clean logs: [run record](export-run.json), [stdout](export.stdout.log.txt), [stderr](export.stderr.log.txt), [input hashes](export-input-sha256.json), [authority fragment](authority-fragment.json). The inherited catalog and HTML input hashes are pinned to the baseline because those two files are projection outputs. All other input hashes must still match current bytes. No editor/import, full exporter, old combat replay or art regeneration occurred.

[`project-reference.py`](project-reference.py) appends four JSON value spans and rebuilds the offline HTML. Actual quote/result, source/output instances, profiles and generation provenance are taken directly from the original Python-decoded model JSON to avoid an extra Godot floating-point serialization roundtrip. Definitions and constraints come from the single authority export. [Projection record](projection.json) and [new entries](new-crafting-entries.json) retain their provenance.

[Result](final-result.json), [preservation](preservation.json) and [card hashes](card-sha256.json) record the outcome. Run it with `python docs/qa/v103-reference/check-reference.py`.

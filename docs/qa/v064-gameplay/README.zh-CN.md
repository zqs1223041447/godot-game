## 事务与只读边界

对真实 main 使用的模型实例，仅在测试子类覆写写盘函数注入失败，生产代码无测试开关。分配和退款失败均检查完整模型字节、磁盘字节、成功保存次数、共享 RNG、全局 RNG、暴击状态、攻击熵、当前资源、派生缓存及信号计数；均保持原值，仅允许失败写入尝试计数增加一次。同一请求重试成功，实际分配只花一个点、增加一个 revision 和信号。断路退款、过期 revision 退款也原子拒绝。

对真实 `get_stats`、`get_defense_conversion_profile` 和 C 面板反复读取、篡改返回副本后，上述只读状态与缓存构建数均不变化。C 面板显示模型最终数值及已计入的转换贡献。当前 schema40 存档经新模型加载后，完整构筑与派生值一致；关闭10661后无新增 stat 键。

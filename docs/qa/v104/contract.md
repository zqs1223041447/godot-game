# 天赋分配与退款原因预览合同

基线：181216b77b4f19078e5e33f6fd1b108afea828ca。当前存档 schema 53、源天赋执行政策 49 保持。

## 唯一权威入口

`CanonicalGameState.passive_action_preview(node_id, mastery_effect = 0)` 返回当前 `revision`，以及 `allocate`、`refund` 两个独立字典；每项包含 `allowed`、`error_code`、`reason`。成功原因为空；失败沿原始事务的检查顺序及原始原因。

原分配和退款命令的参数检查与候选构建移至各自共享私有函数。预览对脱离当前状态的候选调用原 `_prepare_candidate` 与完整 `Rules.reason`；实际命令仍重新构建候选，独立走原 `_commit` 校验和保存。预览不读写磁盘、不发 changed 信号、不消费点数或 RNG，也不承诺后续磁盘保存成功。

## 可见边界

标准主树详情和按钮读取当前选中节点、当前精通选择的预览。不能退款的桥接节点、精通所依赖的显著节点、已插珠宝孔及职业起点沿既有约束解释；特殊珠宝允许的断连分配仍合法。非标准源子树继续仅供浏览。未实装节点不因预览新增而放行。

详情只追加当前主要操作的原因，切换节点或精通时替换旧原因。提交中的 changed 信号不得永久缓存忙碌状态；提交结束后刷新读取当前权威结果。

## 验证范围

仅真实模型分配/退款候选、独立提交和保存失败恢复，及面板当前选择/按钮刷新小集。对照基线两方法的合法性、返回与存档结果；查询前后 typed snapshot、属性、保存计数、磁盘、信号与已存随机状态保持。无战斗、经济、珠宝机制、布局、源词条或存档字段改动。

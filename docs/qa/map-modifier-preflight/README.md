# 地图准备界面的特殊词缀门槛

基线：`205fda514d58b00370033df32c9a42a3a85994eb`。本分支只改 Main 的只读预览接口和现有城镇服务面板，不改地图编译规则、门槛、费用、奖励、词缀机制、存档或 schema 55。

正式入口显示所选挑战档位的实际波次，独立测试入口显示地图原有固定波次。每个特殊词缀显示现有目录门槛；是否可用通过已有 `MapCompiler.compile_normal()` / `compile()` 判定，没有第二份门槛表。切换地图、档位或刷新状态时重新读取当前控件选择，不自动提交草案。

不适用项禁用。降档或切图后已有勾选保持不变，显示具体词缀、所需波次和处理方式，禁用准备与开启。用户可以提高档位、换图，或明确点击“取消不适用的词缀选择”；该操作只移除不适用特殊词缀，保留普通词缀。强制发出禁用按钮信号也不会进入准备事务或入图。正常草案准备仍不收费，费用只沿既有实际入图事务扣除。

- 界面选择、取消、预览、阻断和地形准备取消前后比较库存快照、存档字节、保存计数、草案、世界、地图运行及 RNG；阻断时记录实际准备 API 调用次数。测试的解锁和 12 枚碎片来自有限的既有 canonical 事务夹具，不声称这次进行了战斗或经济验证。

- `git diff --check` 通过。地图编译器、目录、档位目录、库存、存档及美术相对基线均未改动；两份新增测试报告保留相关源 SHA。

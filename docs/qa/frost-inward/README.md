## 规则与实现

成功冰弹主命中结算后，把原45向外冲量替换为朝发射时角色脚下位置的190冲量；魔力×1.20，占原辅助槽。伤害、冰霜类型、弹数、穿透、减速、射程、寿命及冷却保持。既有牵引衰减、怪物移动、分离和墙体规则承接位移；既有霜锁准入与时序保持，独立爆炸不牵引。

生产只修改四文件：牵引兼容／说明、Main施放和命中消费者、原投射运行时的条件事件字段、同源预览。选中的冰霜在原 `_shoot` 中保存脚下原点；原命中事件携带该值，原成功结算入口消费冻结策略。随后不再用旧45向外冲量覆盖。其他投射物不添加该字段。没有第二次命中判定、第二次暴击、另一套载体或移动器。

Compiler、原伤害解析、schema61、库存／交易、能力目录、其他辅助程序、地图、模型与资产保持。658个其他生产／资产文件字节不变；连锁、范围命中、伏击、瞄准、地图完成与重开函数精确保持。新增控制仍可能把敌人拉近，属于位置取舍，不宣称通用强度或性能收益。

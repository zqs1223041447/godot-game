# v081 地图装置可开状态刷新

基线：7475800c1d21688a87a439b59c1ec631845a72da。

正式城镇已经准备Ⅱ档地图、仅有3碎片时，开启按钮禁用。此前在同屏行囊回收宝石获得第4碎片后，模型已允许入图，但地图装置只刷新页脚，按钮与不足提示仍保留旧值；重新准备或重开窗口可恢复，未造成资金丢失或永久坏档。

本批仅修改 town_service_panel.gd。模型和世界事件在地图装置可见时合并为一次延迟状态读取，summary与launch从权威map_draft更新。排队后若窗口隐藏，同样不读取。没有每帧轮询或整窗重建。

未准备的地图、档位、词缀选择仍使按钮禁用。余额刷新不自动准备、不覆盖选择、不采用外部新草案版本；启动沿用原捕获revision及Main准入事务。

后端入图、费用、奖励、存档、背包、字体、图鉴与版本数据的12份输入与基线字节一致，见unchanged-inputs.json。没有新文字、布局、素材、schema、Windows导出、打包、tag或Release。

统一import一次，24.481秒，exit 0，无ERROR。实际UI/模型定向验证结果由 ../v081-map-refresh/ 的原日志和运行记录单列；不把控件信号调用称为实体鼠标、完整自然地图或Windows硬件性能验证。

实际短验一次53项、0失败，6.295秒exit 0，无ERROR。真实回收3→4恢复原开启按钮；未准备选择经4→5仍保留并禁用旧草案；准备后5→1只付4一次，重复信号不再付费、保存或分配run_id。可见多事件合并一次map_draft读取，隐藏/排队后隐藏均零读取。前置通过可信模型事务建立两图Ⅰ档完成及合法物品，未冒充自然战斗通关。

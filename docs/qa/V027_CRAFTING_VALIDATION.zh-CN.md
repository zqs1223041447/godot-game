# v0.27 四工艺定向验收

本批沿 schema18 和真实碎片物品，整体加入赋魔、升格、补缀、重铸。当前已完成的后台定向结果见同目录日志；Root UI 单独记录在 [制作界面验收](ROOT_CRAFTING_UI.zh-CN.md)。旧 v20 的9底材结果只作历史参考，本次重新检查当前14底材、26词缀族、5个资格池。

## 实际目录与经济

独立经济检查：42个底材×阶级解锁区间，756源装备夹具，5040个实际计划，160617项检查零失败。区间从目录所有正权重阶级门槛派生，当前是1–7、8–15、16–30；不是任选三个等级代替证明。

独立按互斥族、前后缀容量及合法条数作动态规划，求所有合法输出的保守回收增值上界：赋魔7、升格19、补缀3、蓝装重铸5、金装重铸14；对应费用8、24、6、10、28，均严格更高。升格19允许放宽“保留原词缀”的限制，因而是安全保守上界，不声称每种源装备都能达到。

以真实碎片数量加持有随机装备的回收价值为势能，回收仅转换价值，旧校准只降低碎片，新四项使势能严格下降。因此本目录预算内制作→回收组合无法凭空增加材料。掉落提供新价值，不属于制作套利证明。随机种子样例用于验证生成路径、原值保留及结果合法性，上界结论来自目录规划。

## 真实事务与消费者

- 73项操作/metadata：固定六项、无选择与非装备禁用、真实费用、仅点击后签发句柄、没有全局RNG或保存、四项实际提交及schema18重开
- 230项边界：精确类型、非法装备、跨前后缀同族互斥、余额不足、无可达结果先拒绝，失败结果无可执行部分
- 286项真实事务：实际多堆碎片一次扣除、原UID/位置、取消、源不符、重复提交、构筑变化、外部重编码、加载清空、写盘失败原字节不变及同种子重试；成功保存/changed各一次
- 27项消费者：实际制作的局部物理词缀进入龙卷当前配方；卸下清除新构筑中的W且旧已编译数据保持；实际制作的额外行装备可安装/绑定并发射蚀影飞弹，卸下后保留宝石而禁用第11行；两药剂的使用充能与恢复状态不被制作重置
- 旧校准canonical25项与直接货币事务44项通过。旧回收/校准继续字面固定v1种子，原费用不变；当前存档版本断言明确为18
- 同源图鉴3488项通过，六项工艺例子经真实规划器与完整schema18候选校验；静态3763锚点、17243链接、64图片通过。与v26相比仅crafting/game_version数据区变化，原64张图鉴PNG逐字节保持

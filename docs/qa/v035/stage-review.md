# v0.35 后台阶段验收

基线为已发布 v0.34，药剂生命回复、魔力回复和有效根怪充能增幅三项一起接入。schema23 只扩已完整实现的源词汇，旧22先严格检查并原字节备份；运行中药剂余量不保存。

已通过纯规则113、迁移49、真实场景消费者46；root药剂文字5项证据复用，共213个定向断言。零增幅23步输出与冻结v34二进制记录逐字节相同。模型实际源节点分配、用瓶、退款、移动背包和换槽，以及主场景原奖励事务均已调用；未把仅调用信号当真实鼠标。当前未做Windows原生或硬件帧率验证。

初轮消费者夹具把生成函数最后的rewards参数错误传false，模型正确不给奖励；第二轮确认带奖励后，夹具在原tick事务之外直接调用私有结算，触发busy期间的保存保护。最终夹具沿既有_begin/_end_progress_transaction边界，并显式确认根怪XP与计数，未改生产奖励/保存逻辑。失败与诊断日志原样保留。

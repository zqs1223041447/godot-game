# v0.40 双资源偷取定向验收

本批为玩家攻击增加生命与法力持续偷取。没有默认赠送比例，来源为真实源天赋；它与已有药剂、自然回复、暴击、母子投射物形成可组合的续航。完整计算见 `v040/leech-rules-contract.md`，节点范围见 `../SOURCE_LEECH_VOCABULARY.zh-CN.md`。

## 已通过的直接路径

9份报告、3,135次检查：纯规则1,213、到期账本59、源解析295、旧门槛和可达性897、存档迁移172、真实源路径154、编译/主场景317、资源边界17、root显示11。计数是断言次数，不是独立场景数。原始日志与映射在 `v040/targeted-validation.json`。

- 207份从未改动v39生成的零偷取配方覆盖十主动的合法零/单/双辅助和普通攻击，逐字节相同。无偷取时不添加快照字段；对照实际伤害、敌人状态和原随机流相同。
- 以防御后真实扣除的护盾与生命之和计算；过量伤害排除，混合伤害按最终分量比例确定物理份额。暴击只改变实际伤害，偷取不再乘一次暴击。未命中、零伤害与尸体不产生预算。
- 每次预算最多为施放时资源上限的10%；每实例基础每秒2%，总恢复基础每秒20%。实例速率与单次上限冻结，总上限读当前构筑。超总上限的部分按原到期时间舍弃，不形成后台积压。一次跨多个到期点的长delta与分段advance结果一致；1,000个乱序到期实例完成后无残留。
- 每个资源单独满额清账，命中时已满不预存。真实升级、药剂、原生魔力回复、拾取和降低资源上限的构筑事务都验证即时清理；生命清理不误删未满的魔力。暂停冻结；死亡、重开、进出测试档与返城清空运行态。
- 真实UID技能施放启动持续恢复，原魔力、冷却债务、失败门禁保留。母/子/返回继承同一冻结配置，后续退款只影响新施放；自然到期独立爆炸虽仍造成伤害，因自身没有attack标签而不获得攻击偷取资格。
- 按旧v24严格解码和词汇验证，原字节备份后迁移25。CRLF、前导空白、非默认UID与revision保持；旧14–24注入新节点、未来版本、备份冲突、外部改写、写盘失败与重试均定向检查。完整旧13链只提交一次最终快照，没有持久化恢复实例。
- 旧19–24的6×4,224条源节点/精通政策记录哈希不变。新增21个完整普通节点，其中20个从七起点经支持路径可达；新增精通效果15133的4个入口前置均未实现，仍不可分配。物理攻击魔力节点27422含未实现攻击消耗效率，继续锁定。真实7/11/13/24点路线最低等级3/7/9/20，不将可达数称为123点能全部分配。

## 证据与早期问题

纯规则与源词汇由独立文件范围实现，测试文件及生产文件哈希核对后整合。Root C/K显示原文件字节复用，真实model/compiled到两处显示额外在317项中检查。早期错误日志全部保留：缺少零速率profile拦截后补上严格校验；测试局部类型/typed Array错误、测试装备便捷接口保存路径与外部写保护冲突、资源夹具值选择均按原约束修正，没有降低断言。迁移样本Git文本归一化由binary属性修正；最终Git blob与实际被测CRLF文件一致，未修改被测字节。

已通过集合没有因为任务暂停、版本文档或打包再跑一遍。最终字体补集、图鉴导出和同PCK短启动/真实命中探针分别验证它们自己的变化，不作为历史全量通过。

## 边界

这是本游戏明确的初版规则，不宣称完整PoE偷取公式。即时、满额保留、过量伤害、护盾、召唤物和条件偷取没有开放。敌方无奖励派生怪受到实际损伤可供偷取，仍不能额外产生击杀奖励或药剂充能。57张物品原图、64张图鉴PNG保持原字节；字体只补偷、扣并保留旧1038字形和度量。未做Windows原生鼠标或硬件帧率验证，也没有600秒检测或历史全量复测。

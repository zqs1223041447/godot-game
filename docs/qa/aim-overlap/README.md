# 共用瞄准的重合目标缺陷

基线 `b92c2e7f4dbb99e58ba379d572851e4461de84b1`。本批选可复现战斗问题，未把上一批连锁构筑说明称为新增兼容，也未新增宝石、辅助白名单或仅用示例代替实现。

## 修复前证据和语义

初始假设是投射技能可能扣费不发射。代码与实际Main复现纠正该假设：单枚载体已有零向量向右回退，投射物会按原数量创建，但整组扇形在更早处已被零方向折叠，且发射位置丢失19单位偏移。奥术飞弹三枚、冰霜五枚、蚀影一枚、龙卷三枚全部从角色中心向右；无移动输入的冲刺则原地扣费。

`before.log/json`：**122检查、29个关联失败**；均为重合情况下的方向、各枚速度／发射位置及冲刺位移。相同拥有构筑下的非重合实际施放保持正常，完整载体形态与快照保存在 `regular` 字段，供修复后逐字段对照。

更早的 `before-setup.log/json` 只到4检查、1失败：合法旧夹具没有蚀影技能组。它是准备失败，未进入战斗复现。没有伪造拥有关系，改为通过正式商人报价／确认购买蚀影8校准碎片，44→36；入背包后装进原空第10组。其余主动和辅助全部复用原已拥有UID。

## 最小生产修复

Main `_aim_direction()` 保留有效鼠标优先和正常最近敌人方向。最近目标的相对方向为零时，保留角色原朝向；原朝向也为零才取向右。先恢复整组发射所需朝向，再进入原扇形、发射偏移与移动路径。上批裂刃局部回退随之删除，统一复用该边界。

不改ProjectileRuntime单枚载体回退、不改技能配方、伤害、资源、冷却、穿透、存档schema61、碰撞或地形。共用帮助函数的普通远程攻击、无移动输入冲刺和裂刃调用都得到有效方向；没有复制新的发射消费者。方向修复不保证重合目标必被投射物命中，实际受击仍由原发射位置、碰撞与命中准入决定。

- `final.log/json`：补充后 **244检查、0失败**。真实鼠标事件仍优先向右，普通远程自动攻击保留朝向，无有效原朝向回退向右，无目标保留原朝向。向前方目标实际发射并推进12步1/60秒，四种技能均通过原弹道碰撞命中，真实伤害分量和标签不变；没有直接调用结算入口伪装弹道证据。

- 破碎遗迹墙边重合场景下，冲刺恢复向右移动并由原身体碰撞截在同侧，0.6秒保护不变；冷却拒绝时位置、资源、状态保持。最终真实保存重载一致，`owned-after.json` 从该测试独立用户目录逐字节复制，`ownership.json` 记录实际蚀影UID `item_000010`、第10主槽、余额36与哈希。
- `cleave-regression.log/json`：上批裂刃边界脚本本次 **294检查、0失败**，零距离命中／牵引、重复冲量覆盖、墙面与地图边界、入口可达和受控清图队列均通过。按本次实际结果记录，没有调整无关历史计数。

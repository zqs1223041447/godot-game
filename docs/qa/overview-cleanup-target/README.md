### 耗时与限制

Godot4.6.3、X11 dummy、Mesa llvmpipe，1280×720。所有进程使用独立 `/tmp` 用户目录，单次上限 45 秒；未封包、改模型或跑长矩阵。

同一密集运行状态下 12 次 `world_context()` 独立取样：最小 0.253ms、平均 1.131ms、最大 6.193ms。原始帧间隔、进程时间监测读数和查询读数均在 JSON 中；进程时间监测读数可能跨多个帧沿用，不能当逐函数计时。

这些是持续演化战斗、软件渲染和很短样本下的观察，包含固定步长追赶及暖机波动；开关两侧都存在高耗时。尚不能把差异或峰值归因于扫描或地图重绘，也不能据此排除小幅回退、声称流畅或证明长期性能。未据此改动生产刷新/绘制机制，原密集场景性能问题保持独立。

复现：用独立 `/tmp/godot-overview-target-*` 或 `/tmp/godot-overview-live-*` 作为 `XDG_DATA_HOME`，设置 `OVERVIEW_OUTPUT` 为已有输出目录，分别执行对应脚本；真实渲染需 `DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1` 和 `--rendering-method gl_compatibility --audio-driver Dummy`。

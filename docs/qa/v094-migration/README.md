- `support:encircling_cleave` 在动态 GemCatalog 中的最低存档版本为52；图标、名称、兼容技能仍取正式目录。正式商店沿用辅助宝石4校准碎片及现有单次报价确认事务；测试城镇和测试随机奖励沿用动态目录。
- 完整冻结 `decode_v51()` / `reason_v51()`，保留原字段集合、源天赋49、装备词汇51、四图旅程、混沌巡逻、物品序号、货币、位置、技能组、绑定、进度与迁移账本校验。原schema≤50拒绝 `chaos_patrol` 的门禁保留。

- 装备词汇独立于存档版本：52明确映射至51，Equipment Catalog显式接收52仍拒绝；旧词汇冻结检查改为比较映射后的装备词汇。源天赋执行策略仍为49。
- 旧混沌装备迁移固定为50→51并调用 `reason_v51()`；默认构筑和加载器继续执行49→50→51→52链。内置构筑没有新宝石或额外碎片，正式26项里程碑宝石表与52次领取序列保持原值。
- schema51加载先验证，再保留 `.v51-backup.json` 原字节，最后原子写52并发布内存。备份失败/冲突、并发外部改写和写盘失败均不发布新构筑；现有安全重试规则保留。

# 探索地图屏外身体绘制优化

基线为已交付 `b06e7d04e26485df145c4ea790ab759a10083fbd`。唯一生产变化在 `scripts/visuals/retained_actor_layer.gd`；572个其他生产输入与基线原字节一致，包括Main、前景、状态、预警、地图、生成与奖励。保持游戏版本0.87、存档schema50及所有素材／字体。没有Windows导出、包、tag、Release或新增截图门槛。

## 改动

每次同步从当前实际viewport四角及canvas逆变换重算可见世界矩形。全部敌人、三个绘制部件身份、完整Y排序和死亡清理保持；只将屏外身体／肢体／阴影隐藏，并省去其配置及重绘命令。进入可见范围的当次同步立即读取当前位置、朝向、动画时刻、尺寸及受击色；不缓存旧屏幕矩形。异常或不可逆变换保留绘制。

几何半径上界为 `sqrt(2) * (1.5r + 8) + 3`，另加逆变换后的屏幕抗锯齿余量。1.5r覆盖翼展，8覆盖当前步态及固定足部偏移，3覆盖最大6单位线宽，外接圆覆盖任意朝向；不是照搬初始诊断所用的140单位分类常量。前景名字、状态、预警、弹体和所有战斗时序均未裁剪。

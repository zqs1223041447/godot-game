# M1 统一实例与迁移阶段

本阶段尚未切换 main 的状态所有者。游戏入口仍为已验证的 schema13 BuildState；以下新模块作为一次性 schema14 迁移与独立菜单的接入基础，不是完整重构的发行验收。

- UnifiedItemCatalog 把现有固定装备、随机装备、普通/特殊珠宝及8主动/16辅助包装成同一UID结构；装备词缀点数和珠宝0.08等小数保持原值。JSON仅对声明为整数的字段做有限、整值、范围检查后恢复整数，不全局取整
- ItemTransferPlan 用完整位置候选交换装备、回收迁移待安置物品、整理背包；满背包、过期修订、类型不符和重叠都拒绝，失败不返回半成品位置。待安置索引在退出队列时压紧，防总实例数减少后旧高索引失效
- CanonicalBuildMigration 先调用原版本验证器，旧v13仍不能注入第三辅助。原5快捷配置变为前5稳定行，剩余3主动填后续行，共10行。已有辅助按各行分别实例化，未配置的旧可用辅助各补一枚，保留16种定义的可用性；所有原装备/珠宝UID、掷值、材料和制作revision保留
- 旧armor/charm映射body_armour/amulet，已合法背包位置优先保持。超出共享96格者保留在待安置队列。原树分配记录进入迁移账，普通点数为原已获总额封顶源123，差额显式记录；默认Scion起点58833已经与源classStartIndex=0核对。该默认不是永远仅支持一个职业
- CanonicalBuildStore 只以统一items/locations作为所有权事实，向外返回副本。位置命令完整验证后先写盘，成功后换内存和发一次changed；失败保持原物品、材料、序号。旧档迁移先保留BOM/空白在内的原始字节，备份冲突或原子写盘失败都不切内存或覆盖源文件；正常保存也检查外部文件修改

完整树规则通过最终validator接口接入。当前保守验证器只接受已核验起点，防止未实现的分配悄悄进入存档；这不代表完整树效果已实现，也不用于宣称全树可玩。官方原始/规范化来源已审查引入开发目录，导出仍排除data/passive_source，不包含官方原画。

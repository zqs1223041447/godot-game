# v105 立体美术样板集成

本批仅主角、crawler、断墙/花圃基台/银杏树三种地景和地表。两个离线三维渲染图集各144帧，共288帧；角色与地景按脚点共用Y排序。其他怪物保持原绘图 fallback，主角图集尚未覆盖全部装备外观。

## 已有检查与实际观察

- 复用 actor 五个定向测试7,914项、地景15项及一次30帧短启动；结果见相邻 `v105-actors` 和 `v105-root-props`。集成者没有重新运行这些检查
- 所有 actor 验证输入的当前SHA与结果清单相同。Main只有四个表现入口变化，其余158个方法正文保持原字节；权威几何、碰撞、战斗、怪物激活、RNG、奖励及存档规则没有改动
- 最后将旧路网填色透明度降至0.12–0.16，防止遮住新地表；仅颜色变化，路线形状和真实碰撞未改，不重复几何检查

- 运行时只加载PNG和清单；Blender模型及生成脚本保存在 `tools/art` 的 `.gdignore` 子目录。缺图缓存不是热更新接口，晚到资产须用新进程查看

# v0.20 制作经济窄范围审查

审查基线：`codex/v020-crafting-growth`，`4d685f01550dc9f49c38888abf40fa9b00e67e26`。本分支只新增本文件与[定向审查测试](../../tests/crafting_expansion_economy_review_test.gd)，未修改制作规则、`BuildState`、UI 或原有测试。

## 结论

按当前 `EquipmentCatalog` 内容，赋魔、升格、补缀和重铸的碎片成本都严格高于任何可达结果可能增加的回收价值。普通装备的回收潜在价值记为 0；魔法为 `1 + tier 总和`；稀有为 `3 + tier 总和`。回收只把物品的潜在价值转成同一种 `calibration_shard`，不会增加“余额 + 库存回收潜在价值”；校准保持稀有度和 tier，却支付两倍回收值。因此新工艺与回收任意交替都不能套利产生材料。

| 工艺 | 实际成本 | 最大回收价值增量上界 | 最小成本余量 |
|---|---:|---:|---:|
| 赋魔 | 8 | 7 | 1 |
| 升格 | 24 | 19 | 5 |
| 补缀 | 6 | 3 | 3 |
| 魔法重铸 | 10 | 5 | 5 |
| 稀有重铸 | 28 | 14 | 14 |

上界按当前九个底材的目录池和所有正权重 tier 解锁区间计算。每个池只包括其 `POOL_PROFILES` 词缀、该底材实际合格的族，以及物品等级已解锁的正权重 tier。独立动态规划按互斥组至多选一族、词缀前后缀容量和稀有度总数上限，求合法装备的 tier 和最大值/最小值。升格上界使用“任一合法稀有输出最大值 − 任一合法魔法输入最小值”，即使两者不能配成同一条升格路线也仍是安全上界；补缀采用全池最高可用 tier，放宽了源物品已占用族的限制，仍是上界。重铸用同稀有度最大输出减最小输入。

这些材料公式只使用稀有度与 tier，roll 数值本身不改变回收收益。测试仍验证实际样例输出遵守 tier 的闭区间数值范围。每个合法输出最多六条，且每类最多三条；最大 tier、最大合法数量和槽位限制都进入上述求界。

## 检查范围

测试从每个底材所属的实际池读取资格表，并从正权重 tier 的解锁点生成等价物品等级区间。当前得到 27 个“底材 × 区间”；每个区间在两端核对可用池签名，并在区间上对 tier 和槽位求界。它没有把逐个采样物品等级或随机 seed 当作完整证明。

在每个底材和区间端点，套件构造普通、魔法1/2条、稀有4/5/6条且覆盖允许的前后缀拆分，再通过只读生产 quote/plan API 检查源输入不变、可达条数、输出目录有效性、词缀族与 tier 资格、保留词缀逐字段不变、费用一致、无材料入账及实际回收增量严格低于费用。魔法2条及稀有6条时补缀因满槽而拒绝；拒绝结果没有部分交易字段。可达条数另与基于实际池、互斥组和槽位的独立组合动态规划逐项对照。

对生产 plan 使用 `-17`、`0`、`41` 三个确定 seed 是反例探针；随机结果探针不承担上界证明。当前定向运行结果：27 个等价区间、486 个输入装备夹具、3,240 个制作计划、103,297 项检查、0 失败。运行命令：

```sh
env XDG_DATA_HOME=/tmp/crafting-economy-review/data \
  XDG_CONFIG_HOME=/tmp/crafting-economy-review/config \
  XDG_CACHE_HOME=/tmp/crafting-economy-review/cache \
  godot --headless --path . --script res://tests/crafting_expansion_economy_review_test.gd
```

## 纯规划器与集成责任

制作规则和 `CraftingTransactionPlanner` 是无钱包副作用的纯计划 API。测试检查 quote 不暴露候选或 seed、输入上下文/余额保持不变、返回的嵌套报价与候选互不别名；只读存档、余额不足、修订号过期及无合法结果都在返回候选前拒绝。

纯规划器是无状态投影：同一上下文、旧 quote 与 seed 可以重复得到同一候选；它本身不消费报价，也不负责并发修订、存档写入或 seed 权威性。生产集成必须由 `BuildState` 持有不透明报价句柄和当前构筑/磁盘快照，拒绝重放或过期报价，从权威规则版本、修订号和源装备派生 seed，完整验证候选，并在写盘成功后再更新内存。相关状态责任由现有 `tests/crafting_state_test.gd` 覆盖；本次只运行新增的定向经济套件，没有重复状态或 UI 矩阵。

掉落和任务奖励等外部材料输入不在该不套利不变量内。结论适用于上述固定提交的目录与工艺公式；未来新增底材、词缀、tier、槽位或回收公式时，应重新运行并检查这套界限。

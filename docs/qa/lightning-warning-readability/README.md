## 复验

从仓库根运行 `tests/lightning_warning_readability_test.gd`，设置隔离的 `XDG_DATA_HOME=/tmp/godot-lightning-readability-<本次名称>` 和非空 `LIGHTNING_QA_OUT=<证据目录>`。例如：

`godot --headless --path . --script res://tests/lightning_warning_readability_test.gd`

去掉 `--headless` 并使用可用原生显示即可保存五张真实viewport截图。测试会重置其隔离存档，禁止指向玩家日常存档。只读图元对照脚本及基线源码保存在上述证据目录，不接入生产运行。

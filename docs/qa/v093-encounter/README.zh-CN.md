## 变更边界

- 蚀影守卫是重壳体普通模板，保留原普通/魔法/稀有及源机制。仅新模板有25%混沌抗性；攻击为纯混沌预警，替代接触。
- 预警锁定玩家起手位置：1秒蓄力、90半径、0.8倍伤害、基础1.8秒恢复、150触发距离。攻速只影响恢复。复用既有锁点调度器、冻结暂停、出生保护与死亡取消；未增加计时器、状态系统或扫描。
- 新特殊词缀“蚀影巡逻”追加于选项末尾，仅选择后在原重壳巡逻入口替换。最低第5波：正式断垣/晴泉/银杏II阶起可选，旧庭III阶起可选；四图I阶和旧庭II阶拒绝。测试旧庭固定第4波拒绝，其他三张固定波地图允许。
- 无 MapCompiler、MapCampState、MAPS描述、保存或奖励路径改动。正式地图沿原特殊完成奖励+2，测试地图0；没有额外怪物奖励池。灰烬、分裂、孵化、首领和后代不替换。
- 混抗仅新模板显式拆出并调用共享 Defense 公式，其他字段仍通过旧 fire-only 严格校验；未知属性、无效类型、非有限值及其他模板擅加混抗均拒绝。

`frozen/` 保存897dbfc的六个纯脚本，只去掉全局类名并重定向这六个依赖。源文件及转换后哈希见 `baseline-manifest.json`。

- 50个旧显式地图配置及完整据点预生成快照与冻结基线原生Variant字节一致，含四图固定波/三阶、无特殊/元素庇护/霜纹/雷纹选择与拒绝。
- 原四版普通采样器在四个波数逐抽样输出及随机状态一致；旧模板完整actor、预警profile、描述与旧调度事件/状态字节一致。
- 三个固定种子产生266个新混沌根怪，涵盖普通、魔法、稀有。除模板身份、伤害类型和混抗外，与原重壳/霜纹actor投影一致；位置、名额、稀有度、源机制、资源、攻速、伤害基底、谱系和奖励资格保持。
- 实际 MapAdmission/MonsterRuntime 验证新模板可准入、首领原样、后代不替换且无奖励、根怪死亡仅奖励一次。
- 既有调度器验证出生保护、整帧/部分冻结、恢复暂停、起手锁点、纯混沌packet、退出105实际相交半径可躲、死亡取消及视觉身份拒绝。

## 伤害与可躲预算

第5波无机制普通守卫基础伤害20.8，单次混沌重击16.64，完整周期2.8秒；站桩理论频率约5.94/秒，低于原重壳每0.85秒接触20.8的约24.47/秒。稀有与源机制沿原基底变化，未增加不可躲接触伤害。

纯几何测试使用200单位/秒的受控步速，在1秒内走出90半径加15玩家半径。该证明只说明开放地形预算可躲，不声称墙角、拥挤或实际手法均无风险。

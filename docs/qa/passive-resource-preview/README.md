# 天赋资源上限预览验证

基线 `d67a1221ec38a290a8b981ccf596acebf4e7df97`。Godot4.6.3，原生 X11 dummy / Mesa llvmpipe，1280×720。每个进程使用独立 `/tmp` 用户目录，上限30或45秒；不封包、不修改模型资产、不运行完整测试矩阵。

- `passive_resource_preview_test.gd`：**238/0**，`report.json` / `native.log`。复用现有合法高等级源树夹具（level119及当前初始装备）；并非自然升级取证。支持节点路径、真实分配、退款、失败保存、重载和原生 T 按钮都使用现有模型／事务。
- `passive_resource_eligibility_test.gd`：**116/0**，`eligibility.log` / `eligibility.json`。原固定事务实现作为差分对照，仅覆盖首点分配、断连拒绝、叶子退款和桥节点断连拒绝。
- `passive_action_presentation_test.gd`：**13/0**，`presentation.log`。覆盖原原因说明、资源变化文本、正负差值、输入快照不变及无变化时不添加行。

资源测试逐项比较预览、实际成功命令、退款逆向变化与重载后的编译值，并沿用原只读检查：规范快照、经济/UID、RNG、统计和技能缓存、保存计数、信号、磁盘字节及回执均不因预览改变。真实 UI 保存失败后角色和文件保持原状态，再次成功操作后立即显示退款预览。

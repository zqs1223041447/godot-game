## 每行实际验证

- 从正式构筑事务装配组合，只调用一次 `main.cast_skill`；验证一次编译、完整初始弹数、精确乘算后的魔力支出和冷却，所有初始载体共享同一施放 ID
- 飞弹/冰霜真实载体的速度、速度向量、减速时长和穿透预算与编译配方一致；射程始终为 650，寿命始终为 1.7 秒
- 以真实扫掠碰撞击中目标，逐种伤害分量对照预览使用的同一原始包，并以无辅助基线乘独立 MORE/类型倍率再次核验。目标有当前物理、火焰、冰霜、闪电和混沌抗性，其中闪电抗性为负；初次命中还经过实际 3 点护盾扣除与生命结算
- 出生保护中的目标不承受主命中或减速；爆炸也不绕过出生保护
- 龙卷每个母箭产生三个真实子箭；子箭逐分量伤害、母子施放 ID、代数和完整冻结快照均核验
- 在飞行结束前移除实时辅助和爆炸装备，旧载体仍使用旧快照自然结束。每行均核验实际中心载体独立爆炸分量等于无辅助基线，爆炸读取命中时的新抗性，不受到任何主命中专用辅助加成或惩罚
- 每个自然结束载体至多一次独立爆炸，终结后继续推进不会重放效果

105 行采用同一种基线：移除初始装备，只通过真实装备 API 装上原有终焰护符，以便同时核验独立爆炸消费者。并未使用合成伤害、伪造命中记录或直接调用伤害结算来替代碰撞。

## 重点补充场景

- **入场原子性**：三个技能分别使用“散束辅助 + 疾咏辅助”和“节能辅助 + 疾咏辅助”。小于编译魔力 0.001 时、尚在冷却时、容量差一格时均拒绝，魔力、冷却、原有投射物、计数、RNG、ID 和战斗效果保持原状；恰好足够魔力或容量可完整施放
- **真实词缀与武器局部阶段**：合法稀有白蜡长弓含本地物理点伤/提高及原有全局词缀，配合龙卷的物理专注辅助与火焰专注辅助；合法符木法器含冰霜/闪电法术点伤，配合飞弹或冰霜双辅助。先断言原始点伤与附加效用，再验证真实命中分量和预览一致
- **在途冻结与下次施放**：飞弹“疾速投射辅助 + 闪电专注辅助”、冰霜“疾速投射辅助 + 寒意延长辅助”先施放。随后真实换辅助、卸下并丢弃词缀武器、交换热键槽；旧飞行继续保留原始速度、减速、伤害包、快照和施放 ID，并读取目标新抗性。下一次施放使用新的缓速强击辅助配置、新减速时长、新消耗/冷却及新 ID
- **既有减速的实际移动效果**：目标受到真实冰霜命中后，调用实际敌人更新。基础与延长减速都保持原有 0.36 移动倍率；原 3 秒截止时，延长版本还剩 1.5 秒；4.5 秒后恢复原速。没有新增异常状态或改变减速强度
- **去返共享穿透**：飞弹/冰霜各组合“贯穿辅助 + 疾速投射辅助”与“贯穿辅助 + 缓速强击辅助”。返回沿用去程已消耗的预算、旧年龄、1.7 秒寿命和施放 ID；相位内不重复命中，同目标只有返回相位可再命中一次。另有目标重新进入下一次扫掠的相位账本检查
- **冰霜搭配缓速强击辅助的寿命边界**：速度 390，抵达 650 射程需约 1.6667 秒，剩余返回时间仅约 0.0333 秒；1.7 秒总行程只有 **663**。测试明确要求其在抵达返回目标之前因寿命终止，不能为慢速偷偷补偿射程或寿命
- **龙卷适配拒绝**：疾速投射辅助、缓速强击辅助、寒意延长辅助的装配事务均原子拒绝；手工损坏运行时辅助数据后，实际施放仍在支付、ID 分配和弹体发射前失败

## 夹具与数值精度

敌人通过场景正式生成 API 创建为 crawler，测试将其设为 100,000 生命、点状碰撞和静止，以隔离中心弹道并避免死亡/掉落打断断言。移动效果专项才将目标速度设为 100，并在真实命中后清除击退，直接观察既有敌人更新。所有伤害包、碰撞、伤害记录、护盾与生命扣除均由生产路径生成。

标量、伤害分量和支付数值使用绝对误差小于 0.0001。Godot 标准版 `Vector2` 使用 float32；速度向量长度单独允许相对误差 `2e-7`，例如 1053 的向量范数可能为 1053.000122。没有为此放宽标量速度、伤害或费用断言。

## 安全运行

脚本在任何存档写入前验证 Linux `XDG_DATA_HOME` 必须位于显式 `/tmp/godot-*` 路径，且 `user://` 解析路径和 `OS.get_user_data_dir()` 完全一致并处于该目录之下。不接触默认用户存档。

```sh
qa_root=$(mktemp -d /tmp/godot-support-projectile-XXXXXX)
mkdir -p "$qa_root/data" "$qa_root/config" "$qa_root/cache"
XDG_DATA_HOME="$qa_root/data" XDG_CONFIG_HOME="$qa_root/config" XDG_CACHE_HOME="$qa_root/cache" \
  godot --headless --path . --script res://tests/support_projectile_batch_integration_test.gd
```

支持 `-- --probe-only`：仅验证隔离路径并退出，不创建构筑存档。正式结果输出：

```text
SUPPORT_PROJECTILE_BATCH {"per_skill_combinations":{"bolt":37,"frost":46,"tornado":22},"rows":105}
Support projectile batch integration: 8041 checks, 0 failures
```

此专项未运行 GUI、600 秒负载、Windows 启动或发布流程。该脚本应纳入同一次最终串行验收，不能将本记录视作整批所有领域已通过的替代证据。

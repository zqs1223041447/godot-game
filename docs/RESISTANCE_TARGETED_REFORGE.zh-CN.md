# 四抗定向重铸合同（v103）

工匠的定向重铸新增火焰、冰霜、闪电和混沌抗性四个方向。选择方向只保证新结果至少包含一条对应的合法抗性后缀；会重新生成全部词缀，不保留旧词缀，也不保证高阶、原有抗性不下降或装备更强。

## 目标与合法底材

| 方向 / operation | 灰烬皮甲 `emberhide_vest` | 纹刻指环 `nine_slot_etched_ring` |
| --- | --- | --- |
| 火焰抗性 `targeted_reforge_fire_resistance` | `emberward` | `ring_emberward` |
| 冰霜抗性 `targeted_reforge_cold_resistance` | `rimeward` | `ring_rimeward` |
| 闪电抗性 `targeted_reforge_lightning_resistance` | `stormward` | `ring_stormward` |
| 混沌抗性 `targeted_reforge_chaos_resistance` | 无合法目标 | `ring_voidward` |

以上都是现有目录中的后缀与原始抗性，不是最大抗性。灰烬皮甲底材自带的15%火抗保留，但它不属于新掷出的 `emberward` 后缀，不能单独满足火抗定向的保证。其他底材没有这四种目标的合法词族；不会因为已经存在底材火抗、相似文字或可提供别的防御而获得资格。

魔法与稀有装备都从物品等级1起有合法结果。阶级仍由物品等级限制：T1为等级1、8%–12%；T2为等级8、13%–18%；T3为等级16、19%–25%。沿用目录的100/60/30正权重，没有保底T3或阶级奖励。高等级装备仍可取得T1。

魔法结果为1–2条词缀，最多1前缀和1后缀；稀有结果为4–6条，最多3前缀和3后缀。因此单枚戒指不能同时拥有四种抗性后缀，保证某一种也不保证其他种类继续存在。底材、词族、阶级、数值、权重和前后缀限制均未改变。

## 费用、确认与保存

- 魔法装备消耗16枚校准碎片，稀有装备消耗40枚；使用背包中的真实碎片堆
- 保留装备UID、底材、物品等级、稀有度与背包位置；原有全部词缀重新生成
- 普通、固定、已穿戴、待安置物品和没有合法目标的底材不能操作
- 首次点击只取得权威报价；确认时仍校验原装备快照、报价句柄、当前上下文与保存状态，再验证完整候选并原子保存
- 取消、旧确认、换选、余额不足、外部存档变化或保存失败，不提交半套装备、材料或制作序号
- 结果可能相同或更差；成功确认后仍会消耗碎片。操作不购买额外随机机会、不添加新钱包或赠送物品

沿用 `crafting_quote(operation, uid, path)` 与 `execute_crafting(handle, source_instance)`。旧六工艺和旧四个方向的ID、顺序、费用、种子版本与生成算法保持；新四个ID只追加在旧四个之后。当前存档schema53与装备词汇51不变，不新增迁移。原有旧词汇兼容分支也不改写；对新方向使用历史词汇时，仍按当时真实词族是否存在决定资格。

## 原始值、有效值与最大抗性

词缀整数值8表示原始抗性增加8个百分点，属性中的比例为0.08。有效抗性由现有防御规则根据原始总和与上限计算，不能把原始抗性直接称为实际减伤，也不能把定向保证称为提高最大抗性。

三元素默认上限75%，已有最大抗性加成沿原规则计算并受83%安全上限约束；混沌使用独立75%上限。该工艺本身不增加任何最大抗性，不改变防御结算。真实模型保存、重新穿戴后的原始值和有效值见[F8四抗条目](reference/index.html#crafting-targeted_reforge_fire_resistance)与[本批证据](qa/v103-reference/README.md)。

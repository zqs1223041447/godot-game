# 手绘奇幻 · 魔法手札 UI（v0.12）

## 已接入的实际表现

用户2026-10-02批准的概念图是画风参考，未被切割成游戏按钮或当整屏背景使用；图中的文字、数值和未实现页面未被导入。

- 羊皮纸正文、深褐墨字、酒红书签、磨旧皮革和旧黄铜包边
- 原创低纹理纸面/皮革按九宫格绘制，保持原有控件边界和边距；HUD为轻量皮革底，正文界面为纸页
- 8种现有主动技能各有独立绘画图标；散束/凝束辅助使用紫/蓝宝石。快捷栏、K选择条、详情和可用技能列表来自同一稳定ID图
- 17件已有装备与4种珠宝分别制作透明绘画，按真实alpha范围保留比例缩放。装备格、详情、天赋珠宝与图鉴复用同一绘制入口
- 天赋节点坐标、缩放、平移、连接和半径数据不变；纸面墨迹连线取代背景仪表式装饰
- 稀有度仍由已有模型给出；右下金色折角用于选中状态，与左上稀有度角标分开
- 两处v0.11火抗提示现在可实际悬停：生命条和背包当前属性摘要

## 保留的行为

三装备槽、12×8背包、五快捷技能槽、每技能两个辅助、全部按钮入口和热键、拖放占格与拒绝规则、天赋预算与特殊珠宝授权、实际伤害/消耗/冷却预览、UI与字体缩放设置保持原模型。没有新增物品类型、辅助、地图、稀有度、战斗公式或存档迁移；沿用v8。

装备详情图在原位置由48增至108逻辑像素高，K当前技能说明旁加入112逻辑像素绘画；较大字号下沿用原滚动容器，不隐藏属性或操作。21:9窗口沿用既有16:9内容视口与留边，不改变世界视野规则。

## 素材来源与资源边界

- `assets/ui/grimoire/asset_manifest.json`：2张材质、8张法术、2张辅助；完整生成提示在同目录`generation_prompts.json`
- `assets/art/equipment/`：17件装备和4种珠宝；该目录清单记录原始字节哈希、来源与完整提示
- 全部新画面由内建图像生成功能原创制作。没有从商业游戏截图或用户概念图裁取生产素材，没有新引入第三方字体
- PNG源文件保持原始字节；Godot导入限制每张运行纹理最大512像素并生成mipmap。装备alpha范围按ID一次缓存，运行时不反复扫描图片，不使用游戏随机数
- 无对应绘画或空槽提示使用原有几何轮廓回退，不用其他物品冒充

## 验收入口

- `tools/validate.sh`包含材质复制、纸面/皮革对比、全部绘画ID映射、模型只读与装备绘画边界检查
- `tests/grimoire_visual_capture.gd`必须在原生图形窗口运行，输出由`GODOT_GRIMOIRE_QA_DIR`指定；覆盖1280×720、1920×1080、2560×1440和2560×1080窗口、常规与110%UI/120%字体
- 使用独立XDG数据/配置/缓存，避免写入真实玩家存档
- 图鉴PNG由`tools/export_reference_art.gd`复用当前运行绘图代码生成

Windows包提供资源与PCK完整性检查；本环境没有Windows/Wine，因此不宣称Windows实机启动已验收。离线图鉴的浏览器交互仍未在本轮验收。

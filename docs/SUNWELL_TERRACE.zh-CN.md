# 晴泉台地：第三地图内容合同

开发候选，稳定地图ID `sunwell_terrace`，首领动作 `sunwell_echo`。数值为本游戏可调原型，不增加货币或改变原有地图阶梯。

- 同一世界边界内，四个实体泉池台座形成中央十字通路与外侧环路。碰撞、出生合法性、寻路、近战与投射物/扩散LOS统一读取障碍矩形；视觉不得扩大真实阻挡
- 西泉、北门、东阶三据点各12个根怪，可任意次序或多组同时激活；整组登记、230安全出生距离、0.6出生保护与100怪上限保持
- 不减少怪群或停攻击。新图基础名额编排分别偏重壳/霜纹、混合与掠行/雷纹；保原稀有度/词缀、灰烬/裂殖/孵化名额，冰电门槛沿波次4/5，特殊词缀优先
- 全36个据点根怪击败后开放首领标记；首领及其后代清完结算，合法根怪/后代奖励规则保持
- 泉脉双响锁定起手玩家点，半径85。0.8秒第一响、再0.8秒第二响，两次中心相同，均可走出。每响为既有接触分量×0.65，总1.3D；恢复基底1.9秒，只有恢复受攻速缩放，两次预警不缩短
- 同一首领最多一次动作，死亡/返城/重开取消整段；不额外添加触身伤害、燃烧、冰冻或感电
- 正式三档wave3/6/10，测试wave6。沿费用0/4/8与完成4/8/12加既有词缀奖；本图I初始可选，II/III按本图完成解锁
- schema30严格先验29、保原字节备份，只新增本图best_tiers=0；原两图进度、在途记录、待领奖励、UID/装备/宝石/天赋与旧奖励序列不变

视觉接口：`world_geometry().walls`为唯一障碍矩形，`obstacle_style=spring_basin`仅新图；landmarks仍沿三据点/首领结构。预警快照`visual_pattern=sunwell_echo`、`pulse_index=0/1`、`pulse_count=2`，显示elapsed每次windup从0至0.8，最后recovery从0.8继续；真实中心始终锁定，不由渲染重算规则。

# 重合目标的瞄准修复

敌人与角色完全重合时，两者之间没有可用方向。此前自动瞄准返回零向量：奥术飞弹、冰霜、蚀影和龙卷仍扣费生成原数量的投射物，但整组弹道都从角色中心向右，丢失原扇形与发射偏移；无移动输入的冲刺则会原地扣费。

现在先确定一个有效方向，再执行原施放：有效鼠标瞄准优先；正常最近目标使用原方向；目标重合时保留角色原朝向，原朝向也为零才向右。普通远程攻击也复用同一规则。裂刃上一批的局部回退合并到这里，重合命中和零距离牵引保持。

修复恢复原扇形、速度、19单位发射偏移及冲刺请求位移，不改变数量、伤害类型、消耗、冷却、穿透、射程、寿命或辅助兼容。是否实际命中仍由原弹道碰撞与准入决定，方向回退不保证重合目标必被某枚投射物命中。

冲刺有移动输入时仍优先沿移动方向；没有移动输入才使用瞄准。175基础／280长跃请求距离继续受身体、地图边界和墙体约束，不允许穿墙。

没有新宝石或存档迁移，schema61保持。原有技能继续从正式商人获得并按UID装配；本次复用已有技能，缺少的蚀影飞弹按8校准碎片正常购买、入包装配和保存重载。相关F8技能与投射规则已同步。

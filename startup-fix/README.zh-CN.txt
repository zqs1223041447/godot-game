Windows 网页游戏本机启动包（64 位）

1. 下载 ZIP 后完整解压到普通文件夹，不要在压缩包预览中运行。
2. 双击 Start-Game.exe，不需要安装 Go、Python 或 Node。
3. 启动器会打开默认浏览器的 http://localhost:18764/ 。如没有自动打开，请手动访问此地址。
4. 游戏期间保持启动器窗口打开。结束后按 Ctrl+C 或关闭启动器窗口。

不要直接双击 index.html。本版本请通过本地服务器或 HTTPS 运行。直接以文件方式打开时，部分浏览器会拦截资源或存档访问。

需要支持 WebGL2、WebAssembly 和 Web Locks 的浏览器。启动器只监听本机 127.0.0.1:18764，不开放局域网、不申请管理员权限、不修改防火墙。端口被占用时会报错退出，不终止其他程序，也不换端口。关闭已有的本游戏启动器后再试。

以后固定使用 http://localhost:18764/ 和同一个浏览器用户配置。localhost、127.0.0.1、不同端口、不同浏览器通常是不同存档来源。本启动器不迁移、覆盖或清理存档。保存后请等待后台保存完成再关闭；隐私模式或清理站点数据可能丢失进度。

此启动器是未签名的新程序。若 Windows 或浏览器阻止运行，请保留提示信息，不要关闭安全保护；可从发布页检查源码和 SHA256 校验值。
